PC本地电脑模式

  • 同一账号授权后，手机端下达任务指令，由已连接的电脑端执行
  • AI 直接操作本机文件、软件、浏览器登录态
  • 进度与结果实时回传手机
  • Windows 独家虚拟桌面，与用户操作互不干扰fhcode 未实现
  • 依赖本机资源，电脑需开机、消耗本机算力

☁云电脑模式

  • 云端独立工作环境，不依赖本机资源
  • 计算密集型 / 长耗时任务交由云端处理，不占用本地算力
  • 本地电脑关机也不影响任务执行
  • 可跨端查看、持续处理，随时发起
  • 不能默认读取本机文件（需主动上传到云端环境）

云电脑落地：三条可行路线
成本 / 周期 / 体验 分级
路线 A · 云端 Agent 复用
≈ 0 元/月增量
  • 在现有腾讯云服务器上部署一套 fhcode Agent（无头模式）
  • 复用现有 bridge 协议，手机选「云电脑」→ 任务发到云端 Agent 执行
  • 适合：文件处理、脚本执行、网页抓取、内容生成等无界面任务
  • 1-2 天可打通，先跑通链路
优点：零新增成本、快速。局限：无图形桌面，无法看屏幕操作
推荐
路线 B · 轻量云电脑 + 网页桌面
≈ 60-130 元/月
  • 腾讯云轻量/CVM 开一台 Linux 或 Windows 云主机
  • 部署 KasmVNC / noVNC：浏览器直接看桌面画面，无需装客户端
  • 云主机内跑 fhcode Agent，手机任务可驱动云端电脑真实执行
  • 支持屏幕截图/画面回传手机，体验最接近豆包云电脑
优点：有真实图形桌面 + 外网浏览器访问，可控可商业化。局限：需维护一台云主机
路线 C · 腾讯云桌面 CVD
≈ 79 元/首月，按量 1.5 元/时
  • 腾讯云官方云桌面服务：分钟级交付、自适应加密传输
  • 无需公网 IP 即可内外网穿透访问，天然适合外网
  • 提供 AI Agent 预装镜像（OpenClaw 等）
  • API/SDK 集成，可程序化创建/管理桌面
优点：免自建、官方托管、体验最好。局限：成本更高、API 部分需商务对接
06
外网访问与安全方案
用户核心诉求：非局域网、外部网络可达

外网可达 ✓ 已满足

fhcode 云端部署在腾讯云（公网 IP 111.229.190.132），入口 https://api.klai.top/fhcode/。手机端无论 4G/5G/WiFi，任何外网环境均可访问；电脑端 bridge 通过长轮询主动连接云端，无需家庭宽带映射、无需内网穿透。

安全体系 ✓ 已有三层

① 激活码授权（仅开发商端生成）；② HMAC 请求签名（时间窗 + nonce 防重放）；③ Bearer 会话令牌 + TLS 传输。云电脑场景可叠加：云主机仅开放 443/指定端口、KasmVNC 设强密码 + 双因素。

云电脑画面通道 需新增

浏览器直连 KasmVNC/noVNC（HTTPS WebSocket）查看桌面；手机端通过云端接口拉取定时截图或低帧率画面流实现「看电脑在干活」。

多执行端路由 需新增

任务下发时带上 executor: local | cloud 字段；云端桥接按执行端把任务路由到本地 bridge 或云端 Agent，与豆包「选执行端」交互一致。
