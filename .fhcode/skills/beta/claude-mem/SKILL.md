# 持久记忆（claude-mem）

> 上游项目：https://github.com/thedotmack/claude-mem ｜ MCP 记忆插件
> 存储：SQLite + Chroma 向量检索；提供 Web 管理面板。

## 触发
当用户希望 AI 在**不同会话之间记住项目上下文**（此前讨论过的需求、决定、坑、偏好），或问"我们之前不是讨论过 X 吗"时使用。

## 前置安装（一次性）
```bash
# 方式一：npm 安装并接入
npx claude-mem install

# 方式二：Claude Code 插件市场
/plugin marketplace add thedotmack/claude-mem
/plugin install claude-mem
```

## 执行步骤
1. 确认记忆服务已启用（首次安装后重启会话）。
2. **写入**：每轮关键结论、用户决策、踩坑、偏好 → 生成简短观测存入记忆库。
3. **压缩**：会话过长时自动摘要并归档，控制记忆体量。
4. **检索**：新会话启动时按语义注入与当前任务相关的历史记忆。
5. **管理**：通过 Web 面板查看/编辑/删除记忆条目，维护记忆卫生。

## 输出格式
```
注入的历史记忆：<与当前任务相关的前情，标注来源会话/时间>
当前会话新写入：<本次新增的关键上下文>
记忆状态：<条目数/最近归档>
```

## 边界
- 只持久化**非敏感**的项目上下文与决策；密钥、token、个人隐私不进记忆库。
- 记忆检索结果仅供参考，需与当前上下文复核，避免过时结论误导。
