## 登录界面

**URL**: `https://www.filmera.ai/studio/login`

### 界面元素
| 元素 | 位置 | 说明 |
| :--- | :--- | :--- |
| 邮箱输入框 | 页面居中，Cloudflare 框上方 | 提示文字 `you@example.com` |
| Cloudflare 验证框 | 邮箱输入框下方 | Turnstile 组件，含「请验证您是真人」复选框 |
| 发送验证码按钮 | Cloudflare 框下方 | 深色圆角按钮 |
| Google 登录按钮 | 「发送验证码」下方 | 含 Google logo，文字「使用 Google 继续」 |
| 分隔线 | 两个登录按钮之间 | 带「或」字 |
| 服务条款链接 | 页面底部 | 小字链接 |

### 已知问题
- Cloudflare Turnstile 在自动化浏览器环境下反复验证失败，点击后显示「故障排除」并回到初始状态。
- Google 登录按钮在 Cloudflare 未通过时可能不可点击。
- **解决方案**：引导用户在本地浏览器手动完成登录，利用持久化 cookie 保持会话。

## Canvas 编辑器界面

**URL 格式**: `https://www.filmera.ai/studio/p/<project-id>/canvas`

### 界面布局（基于首次加载观察）
- **顶部导航栏**：黑色背景，左上角有 `filmera` logo，右上角有用户头像/菜单图标。
- **画布区域**：大面积黑色区域，首次加载时显示多个深色占位矩形框（对应素材/片段位置）。
- **底部区域**：最下方有一个长条形深色输入/操作栏（可能是 AI 助手或提示词输入区）。

### 待补充（需实际登录后探索）
- 左侧素材库面板的具体位置和上传按钮坐标
- 时间线轨道的详细结构
- 字幕/文字面板入口
- 效果/转场面板入口
- 导出按钮的具体位置和导出选项
