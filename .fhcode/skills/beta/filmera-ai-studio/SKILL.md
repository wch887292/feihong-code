# Filmera AI Studio

filmora.ai 是在线 AI 视频剪辑平台，提供 Canvas 式可视化编辑工作室，支持素材导入、时间线剪辑、特效字幕、AI 辅助创作与视频导出。

## 访问与登录

1. 打开 `https://www.filmera.ai/studio`（或用户提供的具体项目 canvas 链接，形如 `/studio/p/<project-id>/canvas`）。
2. **必须先登录才能进入编辑**。登录方式：
   - **邮箱登录**：输入邮箱 → 完成 Cloudflare 人机验证 → 点击「发送验证码」→ 用户提供邮箱中收到的验证码 → 填入后进入工作室。
   - **Google 登录**：点击「使用 Google 继续」→ 跳转 Google 授权页完成登录。
3. **Cloudflare 验证注意事项**：
   - 平台使用 Cloudflare Turnstile 人机验证。在自动化浏览器环境下，点击验证框后可能反复回到「请验证您是真人」初始状态，说明自动化环境被检测拦截。
   - 若验证反复失败，**引导用户手动完成验证和登录**：请用户在自己的浏览器中打开链接，完成 Cloudflare 验证并登录；登录成功后回到自动化环境继续操作（浏览器会话已保持登录态）。
   - 不要反复重试点击验证框，连续 2 次失败即切换为引导用户手动登录的方案。
4. **已配置账号**：登录邮箱为 `wch887292@gmail.com`。浏览器环境已保存持久登录态（cookie），直接打开即保持登录；若失效，按上述邮箱验证码流程重新登录。**不要存储或请求该邮箱的密码**。

## 任务路由

| 用户需求 | 操作入口 |
| :--- | :--- |
| 打开指定项目剪辑 | 用户提供的 `/studio/p/<project-id>/canvas` 链接 |
| 新建项目 | Studio 首页 → 新建项目/创建 Canvas |
| 导入素材 | Canvas 界面左侧素材区 → 上传按钮 |
| 时间线剪辑 | Canvas 底部时间线轨道 |
| 添加字幕/文字 | 左侧文字/字幕面板 |

| 导出视频 | 右上角「导出」按钮 |

## 核心操作流程

### 进入项目
1. 打开用户提供的项目链接或 Studio 首页。
2. 确认已登录；未登录按「访问与登录」流程处理。
3. 等待 Canvas 编辑器完全加载（黑色画布区域出现素材占位块后继续）。

### 素材导入
1. 在 Canvas 界面左侧找到素材上传区域。
2. 点击上传按钮，选择本地视频/图片素材文件。
3. 等待素材上传完成并出现在素材库中。

### 时间线编辑
1. 将素材从素材库拖拽到下方时间线轨道。
2. 拖动素材边缘进行裁剪；拖动素材位置调整顺序。
3. 使用分割工具将素材切开后删除不需要的片段。

### 字幕与特效
1. 从左侧面板打开文字/字幕工具，选择样式后拖到时间线对应位置。
2. 从效果/转场面板选择转场，拖到两段素材之间。

### 导出视频
1. 点击右上角「导出」按钮。
2. 选择导出参数（分辨率、格式、时长等）。
3. 等待渲染完成后下载视频文件。
4. 交付视频给用户前，先下载到本地再用 `present_files` 交付；不要直接引用平台播放链接作为交付物。

## 关键约束

- **Cloudflare 验证**：自动化环境下 Cloudflare Turnstile 大概率无法自动通过；遇到验证失败立即引导用户手动登录，不要反复重试。
- **内容合规**：平台不允许违规内容，所有生成均经过内容审核。遇到此类请求直接拒绝。
- **不重复提交**：导出/渲染任务耗时较长，提交后保持等待、定期截图检查进度；一次提交一个任务。
- **账号安全**：登录态、订阅、积分属于用户账号资产，AI 不得代为开通付费或修改账户设置；涉及付费操作前先向用户确认。
- **项目链接时效**：用户提供的 canvas 链接包含项目 ID，格式为 `/studio/p/<project-id>/canvas`，直接打开即可定位到对应项目。
