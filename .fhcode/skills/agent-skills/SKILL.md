# 全生命周期开发技能包（Agent Skills）

> 上游项目：https://github.com/addyosmani/agent-skills ｜ 生产级完整 SDLC 技能包

## 触发
当用户启动一个"从想法到上线"的完整软件开发任务，或要求按生产级标准推进（而非随手写脚本）时使用。

## 执行步骤（按阶段推进，每阶段有独立验收）
1. **需求定义**：明确目标、用户、验收标准、边界；产出 PRD 级说明。
2. **方案规划**：架构选型、目录结构、数据模型、依赖清单；列出风险与取舍。
3. **编码**：按方案实现，遵守项目规范（AGENTS.md / lint / 命名）；每个文件可独立验证。
4. **测试**：按测试工程师视角补单元/集成测试，覆盖关键路径与边界。
5. **安全审计**：按安全审计角色检查 OWASP Top 10 —— 注入、XSS、敏感信息、权限、依赖风险。
6. **代码评审**：以代码审查员视角分级输出问题（严重/建议/优化）。
7. **发布上线**：构建、冒烟、部署检查；记录环境变量与回滚方案。

## 角色速查
| 角色 | 关注点 | 输出 |
|---|---|---|
| 代码审查员 | 正确性/安全/可维护性/性能 | 分级问题清单 |
| 测试工程师 | 路径覆盖、边界、回归 | 测试用例 + 结果 |
| 安全审计 | OWASP Top 10、依赖风险 | 风险清单 + 修复建议 |

## 输出格式
```
阶段：需求 / 方案 / 编码 / 测试 / 安全 / 评审 / 发布
当前状态：<进行中/完成>
验收项：<逐条>
产物：<文件路径>
待办/风险：<下一步>
```

## 边界
- 未经授权不对外部署、不推送仓库、不改共享系统。
- 安全结论必须可追溯到具体代码位置，不泛泛断言。
