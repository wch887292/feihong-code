# 专业图表设计（Diagram Design）

> 上游项目：https://github.com/cathrynlavery/diagram-design

## 触发
当用户需要：系统/软件架构图、UML 类图/时序图、ER 实体关系图、用户旅程图、流程图；且要求"能用、好看、可直接放进文档/博客"时使用。

## 执行步骤
1. 确认图表类型与用途：架构 / UML / ER / 用户旅程 / 流程。
2. 选定输出载体：优先 HTML/SVG（可交互、矢量清晰）；如需二次编辑，同步导出 Mermaid 或 Excalidraw 源。
3. 内容设计：梳理节点、关系、层次与流向，避免过度复杂（超过 ~7±2 个主节点时分层）。
4. 视觉规范：
   - 配色贴合品牌主色；文本与背景对比度满足 WCAG AA（≥4.5:1）。
   - 字号/间距统一，尺寸可量化；画幅变化后重算布局。
5. 校验：检查对比度、重叠、可读性、语义标签；SVG 可点击元素加 title/aria。
6. 交付：输出可直接内嵌文档/博客的 HTML/SVG 文件。

## 输出格式
```
图类型：<架构/UML/ER/用户旅程/流程>
载体：<HTML | SVG | Mermaid | Excalidraw>
节点数：N   关系数：N
配色：<主色清单 + 对比度结论>
校验结果：<可读性/对比度/重叠>
交付物：<文件路径 或 嵌入代码>
```

## 边界
- 数据不充足时标注为占位，不臆造节点。
- 不把纯文本硬塞进图；复杂信息先用文字分层再入图。
