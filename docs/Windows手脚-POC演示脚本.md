# 客户 POC 演示脚本：AI 操控 Windows 桌面（端到端闭环）

> 用途：给企业客户演示「飞虹 Code 指挥中心 → AI 手脚 → 操控 Windows 原生应用 → 全程留痕」
> 时长：约 3 分钟 ｜ 前置：已完成《Windows 手脚接入指南》安装配置 ｜ 更新：2026-09-08

---

## 0. 演示前检查（30 秒 · 安全第一）

```powershell
# 1. 确认 desktop MCP 已挂载（启动飞虹时日志出现）
#    MCP server attached · desktop · 11 tools / feihong-desktop 已挂载

# 2. 确认取证目录可写
dir %USERPROFILE%\.feihong-code\forensics

# 3. 【关键】确认当前桌面没有用户正在使用的敏感窗口（尤其输入类）
#    演示的 type 动作瞄准「当前前台窗口」——先确认前台是演示目标
```

> ⚠️ **安全红线**：演示全程遵循「先 see 确认焦点 → 再 act」。
> 输入动作瞄准的是前台窗口，若前台是客户的微信/文档，输入会进入客户窗口！

## 2. 演示动作（90 秒 · 对话即操作）

### 2.1 勘察桌面（看）

**对话**：「看看当前桌面有哪些窗口」

**预期**：AI 调用 `feihong_desktop_see`，返回焦点窗口/可见窗口列表。

**给客户讲**：这是「眼睛」——AI 先看清楚环境，不盲目操作。

### 2.2 打开记事本（动）

**对话**：「打开记事本」

**预期**：AI 调用 `feihong_desktop_act { action: 'launch', command: 'notepad.exe' }`，
返回启动结果 + 取证记录。

### 2.3 确认窗口（看 · 二次确认）

**对话**：「确认记事本窗口出现了」

**预期**：`feihong_desktop_see { filter: 'Notepad' }` 返回窗口标题。

> **给客户讲**：AI 操作前会先确认目标窗口存在——这是「先瞄准，再开枪」。

### 2.4 输入内容（动）

**对话**：「在记事本里输入：飞虹 Code 企业 AI 底座演示 2026-09-08」

**预期**：`feihong_desktop_act { action: 'type', windowTitle: 'Notepad', text: '...' }`，
返回 `typed: N` 成功。

### 2.5 验证结果（验）

**对话**：「验证一下输入是否成功」

**预期**：`feihong_desktop_verify { expectWindow: 'Notepad' }` 返回「验证通过：窗口焦点命中」。

**给客户讲**：AI 会截图回读、核对焦点——**做完了还自己检查**，不是"做完就完事"。

### 2.6 展示取证（留痕）

**对话**：「把这次操作的留痕记录给我看」

**预期**：展示 `%USERPROFILE%\.feihong-code\forensics\<runId>\manifest.jsonl`，
逐条显示 launch / type / snapshot 记录。

**给客户讲**：**每一步都有时间戳、动作、结果、截图**——这就是企业合规要的「可审计、可复盘」。

## 4. 演示后清理（30 秒）

```powershell
# 关闭演示打开的记事本（只关本次新增进程，不动客户原有窗口）
powershell -Command "Get-Process notepad | Where-Object { $_.Id -notin @(<演示前进程ID>) } | Stop-Process -Force"
```

> 若演示前无 notepad 进程，直接：`Stop-Process -Name notepad -Force`

## 5. 常见问题（给客户的答疑口径）

- **Q：AI 会不会乱动我的电脑？**
  A：三层防护——① 写操作全部需人工审批；② 危险窗口（任务管理器/系统设置等）硬编码拦截；
  ③ 每一步截图取证，随时可复盘。
- **Q：能操作我们公司的 ERP / Excel 吗？**
  A：能。Excel 内置 VBA 直连（可读写单元格/宏）；ERP 等桌面软件通过 UIA 语义点击，
  不需要对方开放 API。
- **Q：部署在我们公司电脑上安全吗？**
  A：飞虹离线私有化部署，运行时装在本机，不依赖外网；权限按角色划分（operator/admin），
  审计全量留痕。
- **Q：中文软件能操作吗？**
  A：能。UIA 引擎支持中文界面元素定位；键盘输入支持 CJK（自动剪贴板）。
