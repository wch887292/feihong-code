## 二、政企采购为何卡合规

政企/金融/医疗客户采购软件时的硬性门槛通常是：
1. **安全资质**：ISO27001 / 等保 2.0（国内）/ SOC2（出海客户）
2. **数据安全**：私有化部署 + 数据不出域（飞虹 Code 已具备，是优势项）
3. **供应链安全**：SBOM（软件物料清单）、依赖漏洞扫描
4. **审计能力**：操作审计日志、权限隔离（飞虹 Code 已具备 RBAC + 审计日志）

**结论**：飞虹 Code 的**技术控制面（RBAC/审计/私有化/沙箱）已具备相当基础**，缺的是"证书 + 文档 + 第三方背书"，这是可规划的，不是技术不可达。
