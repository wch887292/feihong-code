## 一、快速开始

### 1.1 环境要求

- Node.js ≥ 18（推荐 20/22）
- npm ≥ 9
- git（diff/rollback/并行 worktree 需要）
- Docker（仅 `FH_SANDBOX_MODE=container` 时需要）

### 1.2 安装

```bash
# 方式一：源码构建（推荐）
git clone https://github.com/wch887292/feihong-code.git
cd feihong-code
npm install
npm run build

# 方式二：npm 全局安装
npm install -g feihong-code
fhcode --version   # 验证
```

### 1.3 三秒上手

```bash
# 未配置模型时自动进入离线模式（Mock 驱动闭环），可直接体验
fhcode "写一个 hello.ts"

# 配置真实模型（DeepSeek 示例）后走真实模式
export FH_PROVIDERS='[{"name":"deepseek","type":"openai-compatible","baseUrl":"https://api.deepseek.com/v1","apiKey":"sk-...","tags":["code-gen","reasoning"],"priority":1}]'
fhcode "修复 src/auth.ts 中的 token 校验 bug"
```

## 二、命令速查

```bash
# 基础
fhcode                              进入交互式 REPL（TTY 下自动启用 TUI）
fhcode "<需求>"                      单命令执行一条需求
fhcode --stream "<需求>"             流式输出（任务过程实时可见）
fhcode --yes "<需求>"                跳过审批（危险操作需谨慎）
fhcode --lang zh|en                  设置界面语言

# 只读技能
fhcode /plan "<目标>"                生成实现计划
fhcode /grill [路径]                 红队式代码审查（文本）
fhcode review [路径] [--json]        结构化代码审查（--json 供 IDE/CI 消费）
fhcode /goal "<目标>"                分解并保存高层目标

# 会话管理（M3）
fhcode sessions                      列出历史会话
fhcode resume <id>                   从检查点续跑
fhcode diff [id]                     查看会话/工作区变更
fhcode rollback <id> --yes           回滚会话改动（破坏性）

# 企业能力（M4）
fhcode whoami                        当前租户/用户/角色/配额
fhcode policy                        查看生效 RBAC 策略
fhcode audit [verify]                审计记录 / 哈希链校验
fhcode tenants                       租户用量汇总

# 自我进化（M6/M8/M9）
fhcode model-stats                   模型性能统计
fhcode experiences [路径]            经验库
fhcode code-write "<目标>"            自主编程
fhcode quality-gate [路径]           质量门禁审查
fhcode self-improve                  自我改进统计
fhcode swe "<目标>"                  全自动软件工程 Agent
fhcode team "<目标>"                 多 agent 协作（共享任务板+消息总线）

# 生态
fhcode skill-market search "<关键词>" 搜索技能市场（agentskills.io）
fhcode skill-market install <技能名>  安装技能
fhcode skill-market list             列出本地技能
fhcode plugin install <目录|git URL> 安装插件
fhcode plugin list                   列出插件
fhcode doctor                        环境自检
```

**常用 flag**：`--parallel`（并行 worktree）/ `--repo`（swe 目标仓库/市场源）/ `--context-file <path>`（附加文件上下文）/ `--max-iterations N` / `--max-retries N` / `--plan-only` / `--verify-only` / `--json`。

## 三、模型配置

### 3.1 配置优先级

1. `FH_PROVIDERS`（JSON 数组，最高优先级）
2. `fhcode.config.json`（项目配置文件 `models.providers`）
3. 单环境变量 `FH_MODEL_*`

### 3.2 Ollama 本地模型

```bash
export FH_MODEL_NAME=qwen3:8b
export FH_MODEL_TYPE=ollama
export FH_MODEL_BASE_URL=http://localhost:11434
export FH_MODEL_TAGS=code-gen,reasoning,local
```

### 3.3 DeepSeek / 通义

```bash
# DeepSeek
export FH_PROVIDERS='[{"name":"deepseek","type":"openai-compatible","baseUrl":"https://api.deepseek.com/v1","apiKey":"sk-...","tags":["code-gen","reasoning"],"costPer1k":0.0001}]'
# 通义千问
export FH_PROVIDERS='[{"name":"qwen","type":"openai-compatible","baseUrl":"https://dashscope.aliyuncs.com/compatible-mode/v1","apiKey":"...","tags":["code-gen","long-context"]}]'
```

### 3.4 路由策略

```bash
export FH_MODEL_STRATEGY=cost        # cost | capability | latency
export FH_BUDGET_USD=0.5             # 单任务成本上限（超限熔断）
```
低成本标签 `cheap` 的 provider 会优先承担 `swe`/并行子任务（P1-1 模型分工）。

## 四、典型工作流

### 4.1 单任务

```bash
# 基础
fhcode "实现一个 HTTP 服务器，监听 3000 端口"
# 流式 + 指定上下文文件
fhcode --stream --context-file src/auth.ts "审查并修复此文件中的安全问题"
```

### 4.2 全自动软件工程（swe）

```bash
fhcode swe "修复 src/calc.ts 的 add 函数 bug，让 tests/calc.test.ts 通过" \
  --repo /path/to/project \
  --max-tasks 3 --max-iterations 5
# --plan-only 仅规划 / --verify-only 仅验证 / --max-retries N 自愈重试
```

### 4.3 多 agent 协作（team）

```bash
fhcode team "实现登录模块 并且 添加用户管理 并且 写集成测试"
# 目标自动拆解 → 多 agent 并发认领 → 消息总线汇报 → 团队报告
```

### 4.4 技能市场与插件

```bash
# 从 agentskills.io 搜索并安装技能（安装后任务中自动发现）
fhcode skill-market search "code review"
fhcode skill-market install code-review
# 安装插件（打包 skills+hooks+MCP）
fhcode plugin install ./my-plugin
```

### 4.5 会话恢复与回滚

```bash
fhcode sessions                 # 找到会话 id
fhcode resume <id>              # 中断后续跑
fhcode diff <id>                # 查看改动
fhcode rollback <id> --yes      # 回滚（破坏性）
```

### 4.6 环境自检

```bash
fhcode doctor
# ✅ Node 版本 / git / 模型配置 / 网络连通 / 主目录可写 / 沙箱模式
```

## 六、VSCode 扩展

在 `vscode-extension/` 目录打包（`npx @vscode/vsce package`）或 F5 调试加载：

| 命令 | 说明 |
|------|------|
| `fhcode: 运行任务（附带选区上下文）` | 选中代码自动注入 `<selection>` 上下文 |
| `fhcode: 内联评审当前文件` | `review --json` → 编辑器内联诊断（红/黄/蓝） |
| `fhcode: 就地查看工作区 diff` | 原生 diff 编辑器 HEAD↔工作区 |
| `fhcode: 查看最近任务输出` | 聚焦 Output Channel |

配置：`fhcode.binaryPath` / `fhcode.offline` / `fhcode.reviewOnSave`（保存自动评审，默认开）。

## 七、Web 控制台（云执行）

```bash
fhcode serve --port 8080
# 浏览器打开 http://localhost:8080
```

**任务面板**：输入 token（终端输出的 `FH_WEB_TOKEN`）→ 提交目标 → 轮询状态 → 展开结果详情。

**API 调用**（Bearer 鉴权）：

```bash
TOKEN=$(echo $FH_WEB_TOKEN)
# 提交任务
curl -X POST http://localhost:8080/api/tasks \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"goal":"写一个 hello.ts"}'
# 查询
curl http://localhost:8080/api/tasks -H "Authorization: Bearer $TOKEN"
curl http://localhost:8080/api/tasks/<id> -H "Authorization: Bearer $TOKEN"
# 注册 webhook（任务状态回调，可被 CI 调度）
curl -X POST http://localhost:8080/api/webhook \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"url":"https://your-ci.example.com/hook"}'
```

## 九、沙箱与安全使用

```bash
# 沙箱模式
export FH_SANDBOX_MODE=workspace-write      # 默认
export FH_SANDBOX_MODE=read-only            # 只读勘察（禁写禁执行）
export FH_SANDBOX_MODE=danger-full-access   # 全权限（危险命令仍拦截）
export FH_SANDBOX_MODE=container            # Docker 容器内执行 shell
export FH_SANDBOX_IMAGE=node:22-alpine      # 容器镜像

# 网络域名规则
export FH_NETWORK_DENY=evil.example.com
# export FH_NETWORK_ALLOW=api.example.com

# 确定性 hooks（PreToolUse 非零退出拦截）
export FH_HOOKS='[{"event":"PreToolUse","command":"node scripts/guard.js","tools":["run_shell"]}]'
```

## 十一、常见问题速查

| 问题 | 处理 |
|------|------|
| 未配置模型却想用真实模式 | `FH_PROVIDERS` 或 `FH_MODEL_NAME` 配置后自动进入真实模式 |
| 任务超预算中止 | 调高 `FH_BUDGET_USD` 或角色策略 `maxCostUsd`，用 `resume` 续跑 |
| 配额拒绝（QUOTA_EXCEEDED） | 调整 `FH_TENANT_BUDGET_USD` 或 policy 的 tenantDailyBudgetUsd |
| review 输出为空 | 确认路径为文件或目录且含受支持扩展名（ts/js/tsx/jsx/json/md/py/go/java） |
| 技能市场拉取失败 | 检查网络或设 `FH_SWEBENCH_DATA_URL`/`--repo` 镜像源 |
| 中文/英文切换 | `fhcode --lang en` 或 `FHCODE_LANG=en` |
