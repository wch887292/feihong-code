# 飞虹 Code（fhcode）使用说明书

> 本文为飞虹 Code 的**权威用户文档**，面向使用者与运维人员。技术细节见《技术说明书》。
> 版本 0.1.0（稳定版，含 M4 企业能力 + M5 Web 控制台 BETA + M6 自我进化 + M7 编程能力 + M8 自主迭代）。

**署名**：晋江市飞虹智科技企业管理有限公司 · 飞扬企源研发中心 · 负责人：吴赐虹

---

## 1. 产品简介

飞虹 Code（`fhcode`）是终端 AI 编程智能体。给它一个"目标"，它会自动规划、调用工具、反思并完成；支持多子代理并行、会话恢复与审计。企业版额外提供权限管控、防篡改审计、多租户隔离与成本治理，并可通过 Web 控制台可视化运维。

## 2. 安装

### 环境要求
- Node.js **≥ 18**（推荐 20 LTS）
- 操作系统：Windows / macOS / Linux

### 方式一：npm 全局安装（推荐）
```bash
npm install -g feihong-code
fhcode --help
```

### 方式二：源码构建
```bash
git clone <repo> && cd feihong-code
npm install
npm run build
node dist/cli/index.js --help
```

### 方式三：Docker（稳定部署推荐）
```bash
docker build -t feihong-code .
docker run -p 8080:8080 -e FH_WEB_TOKEN=你的强随机令牌 feihong-code serve
# 或一键编排：
FH_WEB_TOKEN=你的强随机令牌 docker compose up -d
```

### 方式四：安装脚本
```bash
./install.sh
```

## 3. 快速上手

### 第一条目标（离线可用）
```bash
fhcode "创建一个说明文件 README-demo.md，写一句话介绍本项目"
```
未配置模型时自动进入**离线模式**（用本地 mock 完成闭环，成本恒为 0），适合体验与 CI。

### 接入真实模型
在项目根目录创建 `.env`（已被 gitignore，不会入库）：
```
FH_API_KEY=sk-你的密钥
FH_MODEL=你的模型名
FH_BASE_URL=https://你的模型网关
```
真实模式会按用量计量成本；密钥仅存 `.env`，日志中一律脱敏。

## 5. 核心工作流

### 5.1 目标运行
```bash
fhcode "为登录页增加手机号校验，并补充单元测试"
```
智能体将规划、编码、自检，最终给出答案与改动文件清单。

### 5.2 规划与评审
```bash
fhcode /plan "实现支付回调验签"
fhcode /grill src/payment/
```

### 5.3 会话恢复与审计（M3）
任务中断后可续跑，不丢进度：
```bash
fhcode sessions          # 看有哪些检查点
fhcode resume <id>       # 从断点继续
fhcode diff <id>         # 本次会话改了哪些文件
fhcode rollback <id>     # 回滚（未确认/非 git 仓库一律拒绝，防误删）
```

## 6. 企业版使用（M4）

### 6.1 启用企业模式
默认在注入 guard 时启用；可用 `FH_ENTERPRISE=false` 关闭回到社区版。

### 6.2 身份与用量
```bash
export FH_TENANT=acme
export FH_USER=alice
export FH_ROLE=developer
fhcode whoami
```
输出当前租户、用户、角色、隔离目录与今日成本/预算。

### 6.3 权限矩阵查看
```bash
fhcode policy
```
展示四角色（viewer/developer/operator/admin）的工具权限、危险命令与敏感路径黑名单。

### 6.4 审计与取证
```bash
fhcode audit --limit 20     # 最近 20 条（脱敏）
fhcode audit verify         # 校验哈希链是否被篡改，定位断点
```

### 6.5 多租户
```bash
fhcode tenants              # 所有租户用量汇总（物理目录隔离，互不串台）
```
数据落在 `<FH_HOME>/tenants/<tenantId>/`，租户 ID 经正则校验防穿越。

### 6.6 成本治理
- 单任务成本超限会**熔断**（终止并给答案）。
- 租户日预算 `FH_TENANT_BUDGET_USD` 超限会**拒绝新任务**（HTTP 429 语义）并记入审计 `quota:block`。

## 7. Web 控制台（M5 BETA）

> 仅观测、不执行，保持 guard 权威。

### 启动
```bash
export FH_WEB_TOKEN=你的强随机令牌
fhcode serve --port 8080
```
浏览器访问 `http://localhost:8080` 即可看到仪表盘（租户总览 / 策略矩阵 / 审计浏览+verify / 会话列表 / 配额进度条）。

### 鉴权
所有 `/api/*` 需 `Authorization: Bearer <FH_WEB_TOKEN>`；未设或错误令牌一律 401（fail-closed）。生产环境务必用强随机令牌并通过环境变量注入，勿用默认值。

### 端点速查
`/api/health`、`/api/tenants`、`/api/whoami`、`/api/policy`、`/api/audit`、`/api/audit/verify`、`/api/sessions`、`/api/quota`。

## 8. 自我进化能力（M6）

### 模型性能统计
```bash
fhcode model-stats
```
查看各模型提供商的成功率、延迟、成本等性能指标，辅助模型路由决策。

### 经验库管理
```bash
fhcode experiences [路径]
```
列出系统积累的经验记录，包括高效工具调用模式、错误规避模式等。指定路径可查看自定义经验库。

---

## 9. 自主编程能力（M8）

### 自主编写代码
```bash
fhcode code-write "<目标描述>"
```
启动自主编写流程：规划→编写→测试生成→审查→修复→总结，全程自动化完成代码迭代。

### 质量门禁审查
```bash
fhcode quality-gate [路径]
```
对指定目录进行质量门禁审查，包括安全审查、代码质量分析、测试覆盖检查，输出标准化报告。

### 自我改进统计
```bash
fhcode self-improve
```
查看系统自我改进的统计信息，包括反思次数、成功率、平均耗时等指标。

## 10. 配置指南

### .env 示例（真实模型）
```
FH_API_KEY=sk-xxxx
FH_MODEL=xxx
FH_BASE_URL=https://xxxx
FH_OFFLINE=false
```

### 常用环境变量
| 变量 | 作用 |
|------|------|
| `FH_HOME` | 数据根目录 |
| `FH_ENTERPRISE` | 企业模式（`false` 关） |
| `FH_TENANT` / `FH_USER` / `FH_ROLE` | 租户/用户/角色 |
| `FH_TENANT_BUDGET_USD` | 租户日预算 |
| `FH_POLICY` | 策略 JSON 覆盖片段 |
| `FH_WEB_PORT` / `FH_WEB_TOKEN` | Web 控制台端口/令牌 |
| `FH_OFFLINE` | 强制离线 |
| `FH_BUDGET_USD` | 单任务成本告警阈值 |

## 9. 常见问题与故障排查

**Q1. 离线模式能做什么？**
不请求模型，用本地 mock 完成闭环，适合体验、CI 与无网环境；成本恒为 0。

**Q2. 危险命令被拒怎么办？**
`rm -rf /`、`.env` 写入等命中黑名单会被直接拒绝（admin 也拦）。确属必要的运维操作请走受控流程，不要绕过 guard。

**Q3. 配额超限（QUOTA_EXCEEDED）？**
当日租户成本超过 `FH_TENANT_BUDGET_USD`。调高预算或次日再跑；`whoami` 可看已用/上限。

**Q4. 审计校验失败（brokenAt）？**
`audit verify` 返回断点行号，说明审计链在该处不连续或被篡改。检查该时间段的操作记录与文件权限。

**Q5. 租户互相看得到会话？**
不应发生。物理目录隔离 + ID 正则校验保障隔离；`tenants` 与 `sessions` 按租户作用域，CI 已做隔离断言。

**Q6. 想关掉企业能力？**
`FH_ENTERPRISE=false`，行为退回社区版（M3），无感降级。

**Q7. Web 控制台起不来 / 401？**
确认 `FH_WEB_TOKEN` 已设置且请求带 `Authorization: Bearer`；端口被占用换 `--port`。

**Q8. 构建/编译被安全软件拦截？**
本地 Windows 下 `tsc` 编译可能被 Defender 实时扫描短暂锁文件。属环境限制非代码问题；CI（GitHub Actions）是权威构建来源。

**Q9. M8 自主编写功能如何使用？**
通过 `fhcode code-write` 命令启动，系统会自动完成规划、编写、测试、审查、修复全流程。可使用 `quality-gate` 进行质量门禁检查。

**Q10. 如何查看自我进化数据？**
使用 `model-stats` 查看模型性能统计，使用 `experiences` 查看经验库，使用 `self-improve` 查看改进统计。

## 11. 安全与合规须知

- 密钥仅存 `.env`（gitignore），不回显、不入库、日志脱敏。
- 危险操作与敏感路径受 deny 优先策略保护；审批通道缺失即拒绝。
- Web 控制台仅观测不执行，且 fail-closed 鉴权。
- 发布包经白名单校验，`.env`/`src`/`.workbuddy` 不随 `npm publish` 泄露。
- 审计链可验证、防篡改，满足合规取证基本要求。
