## 一、产品简介

飞虹 Code 移动控制台是飞虹 Code（终端 AI 编程智能体）的**手机端控制界面**。它对接部署在腾讯云服务器上的飞虹 Code 后端，让你在手机上随时随地：

- 用自然语言描述需求，发起 AI 编程任务
- 实时查看任务的思维链路（模型推理、工具调用、验证结果、最终回复）
- 管理快捷指令（自动化）、模板库、大模型配置
- 与企业级后端共享同一套任务体系（手机发起的任务与电脑 Web 控制台完全互通）

**两种使用形态**（功能完全一致）：

| 形态 | 说明 | 适用场景 |
|------|------|----------|
| **Android App** | 安装 APK，独立图标启动 | 日常高频使用，像普通 App 一样 |
| **手机浏览器版** | 浏览器直接打开网址，可添加到主屏幕 | 不想安装、临时使用 |

## 二、下载与安装

### 2.1 Android App 安装

**方式一：直接下载 APK**

1. 手机浏览器打开以下地址：

   ```
   https://www.jb.klai.top/m/fhcode-v1.0.0.apk
   ```

2. 下载完成后点击安装。若提示「未知来源」：

   - 点击弹窗中的「设置」→ 允许「来自此来源的应用」
   - 返回继续安装
   - （不同品牌手机路径略有差异：小米/红米：设置-更多设置-安全；华为/荣耀：设置-安全-更多安全设置；OPPO/vivo：设置-安全-未知来源）

3. 安装完成后，桌面出现「飞虹 Code」图标，点击启动。

**方式二：浏览器直接使用**

手机浏览器打开 `https://www.jb.klai.top/m/` 即可直接使用，无需安装。

> 提示：Android 浏览器（Chrome/Edge）打开移动版页面后，菜单中选择「添加到主屏幕」，即可像 App 一样从桌面启动。

### 2.2 环境要求

- Android 8.0（API 26）及以上
- 需要联网（访问服务器域名 www.jb.klai.top，需能正常访问国内网络）

## 三、登录

打开 App 后进入登录页：

1. 输入**手机号码**（任意 11 位手机号即可，演示登录、无短信验证）
2. 点击「手机号登录」
3. 登录成功后自动进入「对话」页

**说明**：

- 登录凭据由 App 内置（App 专用通道），无需手动输入服务器账号密码
- 登录状态保存在本地，下次打开自动恢复；点击「我的-退出登录」可退出
- 若服务器会话过期，会自动跳回登录页并提示

## 五、功能详解

### 5.1 对话页（💬）

对话页是核心操作页，包含三部分：

**① 顶部任务栏**：显示当前任务目标与状态徽章（排队中/执行中/已完成/失败），右侧「＋新建」按钮发起新任务。

**② 消息区**：按时间展示当前任务的完整过程：
- 对话流（你发的指令 + AI 的回复）
- 思维链路（模型推理、工具调用、验证结果）
- 最终回复 / 失败原因

**③ 底部输入栏**：输入指令，点击「▶」发送。

**发起新任务**：

1. 点击顶部「＋新建」
2. 填写任务描述（必填），如：`请读取当前工作区 package.json，告诉我 name 和 version`
3. 选择智能体类型（通用助手/修复代码/编写代码/执行命令）
4. 选择工作区（默认服务器工作区，或指定磁盘目录）
5. 点击「创建任务」，自动跳回对话页实时追踪

**多轮续接**：当前任务执行完成后，直接在输入框继续输入指令，消息会归属**同一任务**继续对话（保持上下文）。

> ⚠️ 任务**执行中**时不能发送新消息，需等待完成。此时发送会提示"任务执行中，请等待完成"。

### 5.2 任务页（📋）

- **查看**：点击任意任务卡片 → 弹出任务详情（目标、状态、智能体、迭代次数、成本、最终结果、错误信息）
- **删除**：长按任务卡片 → 确认后删除
- **刷新**：右上角「刷新」按钮；页面也会每 5 秒自动刷新

任务状态徽章含义：

| 徽章 | 含义 |
|------|------|
| 📥 排队中 | 任务已入队，等待执行 |
| ⏳ 执行中 | AI 正在推理/调用工具 |
| ✅ 已完成 | 执行成功，可查看最终回复 |
| ❌ 失败 | 执行失败，详情中显示原因（常见：未配置大模型） |

### 5.3 自动化（⚡）

快捷指令：把常用目标存成指令，一键发起任务。

**新建**：右上角「＋新建」→ 填名称和目标 → 保存。

**运行**：点击指令卡片「▶ 运行」→ 立即发起任务，可到对话页查看。

**删除**：点击「删除」→ 确认。

### 5.4 模板（📚）

- **内置模板**：8 个（编写新功能/调试 Bug/重构优化/生成测试/撰写文档/代码审查/解释代码/性能优化）
- **我的模板**：自己保存的模板（可在 Web 控制台保存，手机端同步可见）

**使用**：点击模板卡片「填入」→ 模板内容自动填入对话输入框 → 切到对话页补充细节后发送。

### 5.5 我的（👤）

**① 大模型设置**：配置 AI 使用的模型（详见第七章）。

**② 权限设置**：配置任务执行期间 AI 的可读范围与操作权限（详见第八章）。

**③ 外观**：浅色/深色主题切换（自动记忆）。

**④ 关于**：版本信息。

**⑤ 退出登录**：清除本地登录状态。

## 六、思维链路解读指南

对话页的消息区会展示任务全过程的「思维链路」，帮助你理解 AI 在做什么：

| 环节 | 显示 | 含义 |
|------|------|------|
| 🧠 模型推理 | 推理内容 + 使用的模型 | AI 的思考过程 |
| 🔧 调用工具 | 工具名 + 参数 | AI 正在调用文件读写/命令/搜索等工具 |
| ✅ 验证通过 / ❌ 验证失败 | 工具名 + 输出摘要 | 工具执行结果校验 |
| 🩹 自愈重试 | 错误类别 + 轮次 | AI 检测到错误并自我修复重试 |
| 📦 上下文压缩 | 压缩条数 | 长对话自动压缩以节省 Token |
| 📬 最终回复 | 完整回复文本 | 任务的最终答案（点「⚙️」可复制/编辑/分享） |
| ⛔ 任务失败 | 失败原因 | 出错说明 |

## 七、大模型配置指南

> ⚠️ **重要**：服务器默认**未配置大模型**。不配置模型时，任务会入队后失败（显示"任务失败"）。**使用前必须先配置至少一个大模型。**

**配置步骤**：

1. 进入「我的 → 大模型设置」
2. 填写：
   - **模型名称**（必填）：如 `GPT-4o`、`通义千问`、`DeepSeek` 等
   - **API 地址**：OpenAI 兼容接口地址，如 `https://api.openai.com/v1`
   - **密钥（API Key）**：你的模型服务密钥 `sk-...`
   - **推理过程运行内容**（可选）：配置模型在中间推理环节的提示词
3. 点击「保存配置」
4. 如需设为默认：在模型列表中点击「设为默认」

**模型列表操作**：编辑（点「编辑」）、删除（点「删除」）、设默认（非默认模型显示「设为默认」）。

**多模型**：可保存多个模型。任务提交时默认使用"默认模型"，也可在 Web 控制台底部随时切换。

**常用模型 API 地址参考**（需自行申请对应 Key）：

| 服务商 | API 地址 |
|--------|----------|
| OpenAI | https://api.openai.com/v1 |
| DeepSeek | https://api.deepseek.com/v1 |
| 通义千问 | https://dashscope.aliyuncs.com/compatible-mode/v1 |
| 硅基流动 | https://api.siliconflow.cn/v1 |
| 本地 Ollama | http://localhost:11434/v1（仅服务器本机可用） |

## 八、权限设置说明

「我的 → 权限设置」控制任务执行期间 AI 的能力边界：

**可读范围**：

| 选项 | 含义 |
|------|------|
| 仅当前工作区 | AI 只能读取当前工作区目录（推荐） |
| 指定目录 | AI 只能读取你指定的目录路径 |
| 全部文件 | AI 可读取服务器全部文件（谨慎） |

**操作权限**（开关）：

| 权限 | 说明 | 默认 |
|------|------|------|
| 📖 读取文件 | AI 读取文件内容 | 开 |
| ✍️ 写入文件 | AI 修改/创建文件 | 关 |
| ⚡ 执行命令 | AI 在服务器执行 shell 命令 | 关 |
| 🌐 访问网络 | AI 访问互联网 | 开 |
| 🖥 浏览器控制 | AI 控制浏览器 | 关 |

> 提示：写入与执行命令默认关闭是**安全默认**。如需 AI 自动改代码/跑命令，请按需开启；任务在服务器执行，请确认操作影响。

## 九、常见问题（FAQ）

**Q1：任务创建后很快显示"失败"？**
大概率是**未配置大模型**。到「我的 → 大模型设置」添加模型（API 地址 + Key）后重试。查看失败原因：任务列表点该任务 → 详情显示错误信息。

**Q2：发送消息提示"任务执行中，请等待完成"？**
任务正在运行，需等待其完成（状态变为已完成/失败）后才能继续对话。

**Q3：App 打开显示"登录已过期"？**
服务器会话过期，重新手机号登录即可。

**Q4：安装 APK 提示"未知来源"？**
按第 2.1 节说明，在系统设置中允许该来源安装。

**Q5：下载 APK 慢或失败？**
确认网络可访问 `www.jb.klai.top`；可尝试使用手机浏览器方式直接使用。

**Q6：模型配置保存失败？**
检查网络与服务器状态；确认模型名称已填写。

**Q7：删除任务/指令失败？**
任务运行中不能删除，需等执行结束；检查网络。

**Q8：App 卡顿或白屏？**
下拉刷新页面（如有）或完全退出 App 重新打开；检查手机网络。

**Q9：如何保证数据安全？**
- 页面与登录接口受服务器 Basic Auth 保护，仅 App 内置凭据可访问
- 业务 API 全部要求 Bearer 令牌校验（未授权请求一律拒绝）
- 任务在服务器工作区范围执行，写入/命令权限默认关闭
