## 一、双方与定义

**数据处理方（乙方）**：晋江市飞虹智科技企业管理有限公司（统一社会信用代码：【__】）
**数据控制方（甲方）**：【客户全称】

- **"个人数据"**：甲方或其员工在使用飞虹 Code 过程中提交、输入、生成的数据中涉及自然人个人信息的部分
- **"处理"**：收集、存储、使用、加工、传输、提供、删除等

## 二、处理范围与目的

| 项 | 约定 |
|---|---|
| 处理目的 | 提供飞虹 Code 本地部署的 AI 编程智能体功能（代码生成、任务执行、知识检索） |
| 数据类型 | 代码、对话内容、配置、日志、审计记录（不含甲方明确标注的敏感个人信息类型） |
| 处理方式 | 乙方软件在甲方指定的本地服务器/终端运行；默认不向乙方服务器回传 |
| 数据位置 | 甲方本地（`~/.feihong-code` 或甲方指定目录）；乙方不托管 |

## 三、双方义务

### 3.1 甲方（控制方）义务
1. 保证其输入数据的合法性，取得必要的用户授权
2. 按最小必要原则使用，配置 RBAC 控制访问权限
3. 依据法律保存必要审计记录

### 3.2 乙方（处理方）义务
1. **仅在甲方本地处理**：软件不主动外传个人数据；联网仅为模型调用（可配置离线模式完全关闭）
2. 提供访问控制、审计日志、数据删除（`fhcode` 数据目录清理）机制
3. 配合甲方行使数据权利（访问 / 更正 / 删除 / 导出）
4. 发现安全事件 48 小时内通知甲方
5. 不向第三方出售个人数据

## 四、安全措施（对应《安全白皮书 v7.2.0》）

- RBAC 权限隔离 + 多租户（企业模式）
- 审计日志（命令与关键操作可追溯）
- 沙箱隔离（read-only / workspace-write / container）
- 供应链安全（SBOM + npm audit + osv-scanner）
- 密钥环境变量注入，禁止明文落盘

## 五、数据留存与删除

1. 默认留存：会话 / 审计 / 经验库在甲方本地按配置留存
2. 删除：甲方可随时清理数据目录；乙方提供删除指引
3. 合同终止后：甲方删除本地数据或按甲方要求移交

## 六、违约责任与争议

1. 因乙方过错导致的数据泄露，乙方依法承担相应责任
2. 争议解决：提交甲方所在地有管辖权的人民法院

## 七、生效与变更

本协议自双方盖章之日起生效；变更需双方书面确认。本模板空白项【】由双方填写后成为有效协议文本。
