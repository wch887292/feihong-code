### 4.1 飞虹 Code 的**真实**差异化优势（不粉饰，但确实存在）
1. **自主产权引擎**：multi-agent 协同、event-driven 事件驱动、MCP 框架、changes 审批、memory、office——**全部实测 200 且代码自研**（非套壳），这是 Trae/Cursor 之外少有的"自研全家桶"。
2. **隐私/离线**：自托管 + 本地模型支持（对应 opencode 卖点，飞虹同样具备）。
3. **中文优先**：实测中文指令解析正常（voice"打开文件"→ open_file，confidence 1）。
4. **企业合规底座**：enterprise/office/self-correction 模块齐备（对比 WorkBuddy 定位）。

### 4.2 飞虹 Code 的**真实**短板（对标结论）
1. **无自有模型** → 代码质量天花板由外部模型决定（豆包/Cursor/Trae 有模型护城河）。
2. **LSP 0 引用** → 无 IDE 语义理解（Claude Code/opencode 的"全仓库推理"飞虹做不到）。
3. **前端体验断层** → v7.2 新增 API 前端 0 调用；无 ghost text、无多文件 diff 可视化、无 TUI。
4. **SWE-bench 未跑分** → 无法用硬指标证明代码能力（有 harness 但没跑，等于没有）。
5. **生态为 0** → plugins market 只返回内置 100 技能，无第三方生态。
