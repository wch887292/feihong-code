## 一、这是什么

飞虹 Code 是一款终端 AI 编程智能体（对标 Muse Code / Claude Code / Cursor CLI），以自研内核实现差异化：
多模型路由、企业级 RBAC/审计/多租户、全自动 SWE Agent、桌面手脚（Windows 原生操控）、AI 员工军团。

**v8.0.1 定位**：在 v8.0.0 基础上，把「AI 操控电脑」与「企业 AI 员工军团」两条主线接进飞虹，
形成「指挥中心 → 手脚」的完整闭环，并完成全仓脱敏与清理加固。

## 二、安装

```bash
# 全局安装（CLI）
npm install -g feihong-code
fhcode --version          # v8.0.1

# 或从源码运行（开发）
git clone https://github.com/wch887292/feihong-code.git

npm run build
```

环境要求：Node ≥ 18（推荐 20+）；Windows / Linux / macOS。

## 四、新能力一：桌面手脚（Windows 原生操控）

让飞虹直接操作本机原生 app（记事本、WPS、剪映、客户 ERP 等），三步开启：

1. **配置**（零代码）：`%USERPROFILE%\.feihong-code\fhcode.config.json` 已内置 `mcp.servers[0]`（name=desktop），
   指向 desktop-touch MCP 运行时并带 11 个工具白名单。首次运行自动挂载。
2. **使用**（3 个原生工具）：
   | 工具 | 作用 |
   |---|---|
   | `feihong_desktop_see` | 只读勘察：看屏幕/窗口树/服务器状态，可 filter 精确窗口 |
   | `feihong_desktop_act` | 写操作：launch / focus / click / type / drag / scroll / 终端命令，自动过守卫 |
   | `feihong_desktop_verify` | 验证：截图 + 状态回读，断言 expectText / expectWindow |
3. **安全护栏**（内置）：
   - 写操作一律需审批（operator/admin），只读沙箱直接拦截；
   - 危险窗口停手线：任务管理器 / 注册表编辑器 / UAC / Windows 安全中心 / 系统配置 / 设备管理器 / 磁盘管理 / 本地组策略，子串匹配管理员也拦；
   - 环境变量 `FEIHONG_DESKTOP_BLOCK_WINDOWS` 可扩展黑名单；
   - 每步操作取证留痕（JSONL + 截图），目录 `<FH_HOME>/forensics/<runId>/`，`FH_FORENSICS_DIR` 可覆盖。

> 演示话术：「打开记事本，输入『你好飞虹』，截图验证」——飞虹会走 see→act→verify 全流程。

| L5 管理 | 11 一人公司AI员工调度官 |

使用方式：

```bash
# 飞虹原生工具（推荐）
feihong_agents_list                     # 员工清单 / scope=stats 任务统计（只读）
feihong_agents_submit agentId=1 input='{"channels":"[朋友圈,抖音]","keywords":"企业AI"}'  # 需审批

# 或命令行直接跑（agent-team/ 目录内）
python main.py list-agents
python main.py submit --module 01 --input '{"channels":"[A,B]","keywords":"测试"}'
python main.py run-once
```

- 模型路由：自动复用飞虹 `models.providers` 第一个 openai-compatible 带 key 的 provider；
  无配置时回退 mock（本地确定性，全链路可跑）。
- 17 个技能（SKILL.md + run.py）已安装到用户级技能目录，对话中按触发场景自动加载。
- 技能也可独立跑：`python run.py --input '{...}'`（纯标准库，`--llm` 可接豆包 API）。

## 七、安全与合规

- **权限**：RBAC 五角色（viewer/developer/operator/admin），写操作需审批，成本上限控制；
- **脱敏**：审计日志自动脱敏 API Key / token（`sk-*` → `***`）；
- **桌面手脚**：危险窗口停手线 + 写操作审批 + 取证留痕；
- **AI 员工军团**：任务提交需审批，apiKey 只作为子进程环境变量传递，不回显不落盘；
- **密钥管理**：所有密钥只从环境变量 / 用户级配置读取，禁止硬编码进代码或提交进仓库。

## 八、常见问题

**Q1：desktop 工具报「AutoGuardBlocked」？**
键盘/鼠标动作被 desktop-touch 感知守卫拦截。先 `feihong_desktop_see` 拿到精确窗口标题再 act；
type 时传 `windowTitle:'@active'` 瞄准当前前台窗口。

**Q2：AI 员工提交后没执行？**
`executeNow=false` 时任务入队，需 `run-once`（或 `feihong_agents_submit` 默认 executeNow=true 立即执行）。

**Q3：npm 包 build 报 copy-web 崩溃？**
v8.0.1 已修复：`fs.cpSync(recursive)` 在 Node 22 Windows 触发原生崩溃，已重写为手写递归复制。

**Q4：历史提交过密钥怎么办？**
本仓库已用 filter-branch 全历史清除泄露密钥并 force push；**请同步到对应平台后台轮换该密钥**。
