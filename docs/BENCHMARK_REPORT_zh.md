- 相比纯 CLI 工具（Aider），飞虹 Code 的 Web/桌面界面降低了使用门槛

## 十二、总结

### 12.1 飞虹 Code 的领先优势

1. **完全免费开源**：零授权费用，企业使用无成本压力
2. **私有化部署**：数据完全不出域，满足金融、政府等强监管行业需求
3. **国内生态优化**：原生支持 DeepSeek、通义千问等国内模型，无需翻墙
4. **中英文双语**：完整的国际化支持
5. **全平台形态**：CLI + Web + 桌面，满足不同使用场景
6. **企业级安全**：RBAC、审计日志、权限审批一应俱全
7. **多模态交互**：截图、语音、视频、电脑控制等特色功能

### 12.2 待改进方向

1. **代码补全能力**：缺少 IDE 内实时补全，可考虑开发 VS Code 插件
2. **Agent 智能度**：任务规划和长上下文管理需持续优化
3. **企业集成**：SSO、LDAP、合规认证等企业级功能待完善
4. **生态建设**：插件市场、模型商店、社区生态需培育
5. **界面体验**：UI/UX 细节与成熟产品仍有差距
6. **文档完善**：私有化部署最佳实践、运维手册需补充

### 12.3 市场定位建议

飞虹 Code 应聚焦以下细分市场：
- **国内企业私有化部署**：对标 Tabnine 企业版，但价格优势明显
- **信创/国产化场景**：支持国产模型和国产操作系统
- **教育与个人开发者**：完全免费，降低 AI 编程门槛
- **多模态 AI 编程**：截图、语音、电脑控制等特色功能形成差异化

## 十三、SWE-bench 真实成绩对标（量化，v7.2.0 新增）

> 本节所有数字均有来源与口径标注，替代早期版本中无依据的定性对标（如"同一梯队""仍有差距"）。
> **关键诚实声明**：飞虹 Code 的成绩是**自建 SWE-bench 格式任务集**的可复现实测；行业数字为官方/权威公开的 **SWE-bench Verified** 成绩。两者**评测集不同，不可直接横向对比**，用途仅为展示"同类评测框架下的相对量级"。

### 13.1 飞虹 Code 真实跑分（自建 SWE-bench 格式任务集）

| 指标 | 成绩 | 口径 |
|---|---|---|
| **测试通过率** | **80%（4/5）** | SWE-bench 格式（problem_statement + FAIL_TO_PASS）自建 5 个自包含 JS 任务；真实模型 agnes-2.5-flash 驱动 Orchestrator；**预定义测试（不交给模型）node --test 真实断言** |
| 通过实例 | swe-js-001/002/003/005 | maxOf / fibonacci / isPalindrome / countWords 全部断言通过 |
| 失败实例 | swe-js-004（findMissing） | iterations=0 toolCalls=0，模型调用未产出，属执行层失败非实现错误 |
| harness 闭环（mock） | 2/2 = 100% | loader→executor→verifier→reporter 全链路真实可执行 |
| harness 真实模型生成率 | 3/3 = 100% | 真实模型驱动 Orchestrator，3 个真实编程任务全部生成目标文件 |

复现命令：`node scripts/_swe-bench-real.mjs`（真实跑分）、`node scripts/_swe-smoke.mjs`（mock 闭环）。
**此为本项目唯一对外声称的跑分；未经真实数据集 + 容器环境复测前，不对官方 SWE-bench Verified 声明成绩。**
