# 飞虹 Code 配置参考

> 晋江市飞虹智科技企业管理有限公司 · 飞扬企源研发中心 · 负责人：吴赐虹

所有配置通过**环境变量**提供，启动时集中校验（fail-fast）。`.env` 文件会被自动加载（仅注入未设置的键），但**切勿提交 `.env`**。

---

## 1. 环境变量总览

| 变量 | 必填 | 说明 | 默认 |
| --- | --- | --- | --- |
| `FH_HOME` | 否 | 应用主目录（目标/日志根） | `~/.feihong-code` |
| `FH_LOG_DIR` | 否 | 会话事件日志目录 | `~/.feihong-code/sessions` |
| `FH_PROVIDERS` | 否* | 模型供应商 JSON 数组；为空则离线 | `[]` |
| `FH_MODEL_STRATEGY` | 否 | 路由策略 | `cost` |
| `FH_BUDGET_USD` | 否 | 单任务预算（美元，超限仅告警） | `0.5` |
| `FH_SHELL_ALLOW` | 否 | shell 白名单（逗号分隔） | 空 |
| `FH_REQUIRE_APPROVAL` | 否 | 危险操作是否需审批 | `true` |
| `FH_OFFLINE` | 否 | 设为 `true` 强制离线 | 未设 |

> *`FH_PROVIDERS` 缺省或 `[]` → 自动离线（Mock 闭环）；非空 → 真实模式。

---

## 2. FH_PROVIDERS 结构

JSON 数组，每项一个供应商：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | ✅ | 唯一标识（用于日志/路由） |
| `type` | `"openai-compatible"` \| `"ollama"` | ✅ | 供应商类型 |
| `baseURL` | string | ✅ | API 基地址（不含末尾斜杠会被规范化） |
| `apiKey` | string | 否 | OpenAI 兼容网关的 Bearer Token；Ollama 留空 |
| `model` | string | 否 | 模型名（openai-compatible 必填；Ollama 指定本地模型） |
| `tags` | `CapabilityTag[]` | ✅ | 能力标签，用于路由筛选 |
| `costPer1k` | number | 否 | 每千 token 成本（USD），用于成本计量与 `cost` 策略 |

### CapabilityTag 枚举

`code-gen` · `reasoning` · `long-context` · `vision` · `cheap` · `local`

编排器调用时默认带 `['code-gen']` 标签筛选；路由按策略对命中供应商打分选优。

---

## 3. 路由策略（FH_MODEL_STRATEGY）

| 策略 | 选优逻辑 |
| --- | --- |
| `cost` | 优先 `costPer1k` 最低（默认，省钱） |
| `capability` | 优先 `reasoning` + `code-gen` 标签命中 |
| `latency` | 优先 `local`（Ollama 等本地模型） |

多供应商时按策略排序，调用失败时**自动 fallback** 到下一个。

## 4. 供应商示例

### 4.1 OpenAI 兼容（Agnes，已验证）

```json
[{"id":"agnes","type":"openai-compatible","baseURL":"https://api.agnes-ai.cn/v1","apiKey":"<key>","model":"agnes-2.5-flash","tags":["code-gen"],"costPer1k":0.001}]
```

### 4.2 DeepSeek

```json
[{"id":"deepseek","type":"openai-compatible","baseURL":"https://api.deepseek.com/v1","apiKey":"sk-xxx","model":"deepseek-chat","tags":["code-gen","cheap"],"costPer1k":0.0001}]
```

### 4.3 通义千问（DashScope 兼容模式）

```json
[{"id":"qwen","type":"openai-compatible","baseURL":"https://dashscope.aliyuncs.com/compatible-mode/v1","apiKey":"sk-xxx","model":"qwen-plus","tags":["code-gen","long-context"],"costPer1k":0.0002}]
```

### 4.4 Ollama（本地，零成本）

```json
[{"id":"ollama","type":"ollama","baseURL":"http://localhost:11434","apiKey":"","model":"qwen2.5-coder:7b","tags":["code-gen","local"],"costPer1k":0}]
```

### 4.5 多供应商（路由 + fallback）

```json
[
  {"id":"deepseek","type":"openai-compatible","baseURL":"https://api.deepseek.com/v1","apiKey":"sk-xxx","model":"deepseek-chat","tags":["code-gen","cheap"],"costPer1k":0.0001},
  {"id":"ollama","type":"ollama","baseURL":"http://localhost:11434","apiKey":"","model":"qwen2.5-coder:7b","tags":["code-gen","local"],"costPer1k":0}
]
```

## 5. 成本计量

- 每次 `chat` 返回 `usage`（prompt/completion/total tokens），按 `costPer1k` 估算 `costUsd`。
- 累加进任务总成本，打印在结果中。
- 超过 `FH_BUDGET_USD` 仅**告警日志**，不阻断（避免半途中断）。
- 离线模式成本为 `0`。

---

## 6. 安全配置建议

1. `FH_SHELL_ALLOW` 遵循**最小权限**：只放确实需要的命令（如 `git,npm,node`）。
2. 保持 `FH_REQUIRE_APPROVAL=true`；仅在完全可信的隔离环境才设 `false`。
3. `.env` 权限设为仅本人可读：`chmod 600 .env`。
4. 不要把 `.env` 提交到 Git（已被 `.gitignore` 排除）。
5. 日志目录（`FH_LOG_DIR`）可能含任务上下文，按敏感数据处理。
