# 数据处理协议（DPA）

> 版本：v1.0 · 更新：2026-08-26
> 晋江市飞虹智科技企业管理有限公司（以下简称「处理方」）与数据处理委托方（以下简称「控制方」）
> 就「飞虹 Code」软件及服务处理个人数据相关事宜达成协议。本协议为政企售前/签约配套材料。

> **📋 性质声明（自评估材料）**：本协议为**软件提供方自行起草的合同底稿**，其中对安全控制措施与合规状态的描述均为**内部自评估结论**，**不构成** SOC 2 / ISO 27001 等任何第三方认证或独立审计意见。签署前须由双方法务复核并按实际部署情况修订；如需认证背书，以第三方审计机构正式报告为准。

## 1. 定义与角色

- **控制方**：决定处理目的与方式的组织/个人（使用飞虹 Code 的客户）
- **处理方**：晋江市飞虹智科技企业管理有限公司（软件提供方）及其授权支持人员
- **数据主体**：控制方系统中的自然人（如客户员工、最终用户）

## 2. 处理的数据类别

| 类别 | 说明 | 默认是否落盘 |
|---|---|---|
| 用户输入（代码/文本/指令） | 控制方在使用飞虹 Code 时提交的内容 | 本地工作区（默认） |
| 配置文件 | 模型供应商配置、token（经安全存储加密） | 本地安全存储 |
| 运行日志 | 事件日志、审计记录 | 本地（支持关闭） |
| 遥测/用量（如启用） | 功能用量统计 | 需控制方显式开启 |
| 不收集 | 键盘记录、屏幕内容、未经授权的通讯录/文件 | — |

**关键承诺**：飞虹 Code 采用**本地优先**架构，代码与配置默认不出本地；模型调用是否出域由控制方选择的模型供应商决定（可配置为私有化/本地模型，实现数据不出域）。

## 3. 处理目的与法律依据

- 处理目的：提供代码补全、Agent 任务执行、会话管理与质量改进
- 法律依据：《个人信息保护法》（PIPL）下的「履行合同所必需」及「控制方合法处理」
- 处理期限：控制方卸载/删除数据后 30 日内删除相关本地副本（法律法规另有规定的除外）

## 4. 处理方义务

1. 按控制方书面指示处理数据，不得用于约定目的之外
2. 采取安全措施：本地沙箱隔离、命令审批、变更审批流、审计哈希链、凭证加密、供应链安全 CI
3. 不向第三方传输数据（除控制方明确选择的模型供应商，且以控制方配置为准）
4. 发生数据安全事件时，按 PIPL 通知控制方与监管机构（如适用）
5. 提供数据主体权利响应支持：查询、更正、删除

## 5. 控制方义务

1. 确保其数据处理行为合法（获得数据主体授权等）
2. 对输出的数据内容负责（不输入违法违规/涉密数据）
3. 合理配置安全策略（沙箱档位、审批、网络白名单等），按使用场景选择本地/私有化模型实现数据不出域

## 6. 跨境传输

- 默认无跨境传输；若控制方选择境外模型供应商，跨境传输由控制方基于该供应商的合规声明自行决策，处理方不承担该环节合规责任
- 处理方如需跨境支持访问（如远程排障），须取得控制方书面同意并最小化数据范围

## 7. 违约责任与争议

- 因处理方过错导致数据泄露的，处理方按《民法典》及相关法规承担赔偿责任
- 因控制方输入违法内容/错误配置导致的后果，由控制方承担
- 争议协商解决，协商不成提交处理方所在地有管辖权法院

## 8. 附则

- 本协议作为软件采购/服务协议附件，冲突时以主协议为准
- 更新时提前 30 日通知控制方；控制方不接受更新的可停止使用
- 本协议不构成对第三方（含模型供应商）的义务承诺
