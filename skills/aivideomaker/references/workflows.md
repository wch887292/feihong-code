# Aivideomaker 详细页面工作流

> 本文档记录 2026-09 实测的中文站点界面结构与参数细节。界面可能随站点改版变化，执行时以实际截图为准，本文件仅作初始定位参考。

## 通用导航（全站）

- 顶部导航（主页）：`创建视频与图片`（下拉：AI视频延长器、AI视频增强器）、`视频增强`、`方案与积分`、`更多`（下拉：一致性角色、特效、APIs、技能）。
- 左侧导航（工具页）：首页 / 创建视频与图片 / AI视频生成器 / AI图片编辑器 / 动作克隆 / AI会说话的照片 / AI图像生成器 / AI视频助手 / AI音频生成器 / 视频增强 / AI视频增强器 / AI视频延长器 / AI角色与用户生成内容（一致性角色、特效）/ API与技能（APIs、技能）。
- 右上角：语言切换（ZH）、登录按钮。

## 主页 `/zh`（快捷生成）

- 选项卡：「图片转视频」/「文本转视频」。
- 输入框「描述你的视频」：0/1000 字符。
- 「图片转视频」专属：上传图像按钮（JPG/PNG/WEBP，≤10MB）、「添加结尾帧」开关。
- 「高级」下拉：视频时长 5s / 10s；分辨率 480P / 720P / 1080P。
- 底部「免费开始」：未填提示词时禁用。
- 未登录时页面提示「正在加载账户信息」，生成会被要求登录。

## AI 视频生成器 `/zh/ai-video-generator`

- 输入模式选项卡：
  - **仅文字**：提示词输入框（必填）。
  - **首尾帧**：首帧图上传（必填）、尾帧图上传（可选）。
  - **参考素材**：参考图片（最多 4 张，2×2 网格）、参考视频（最多 1 个）、参考音频（最多 2 条）。
- 参数条（默认）：画面比例 16:9、分辨率 480P、时长 5s、模式 快速。
- 按钮：「生成 免费」；未填必填项时禁用。
- 右侧为功能说明/示例展示区。

## 视频增强 `/zh/video-upscaler`

- 上传区：「上传您的视频或拖拽到此处」（MP4/MOV/WEBM，≤200MB）。
- 目标分辨率：720P / 1080P / 2K。
- 按钮：「开始增强」（无视频时禁用）。
- 高级功能，需订阅或积分；免费账户触发升级引导。

## 视频延长 `/zh/extend-video`

- 上传区：视频 **≤15 秒**。
- 提示词输入框：0/500 字符，描述续写内容。
- 时长滑块：默认 5s，可拖动调节续写时长。
- 按钮：「立即延长」（需要积分）。

## AI 会说话的照片 `/zh/ai-talking-photo`

- 上传图片区。
- 内容来源选项卡：「脚本」（输入朗读文本，0/500 字符）/「音频」（上传音频）。
- 提示词输入框：建议英文，0/3000 字符，官方提示"请用英文描述你的视频（不要包含敏感内容）"。
- 按钮：「生成」。

## AI 图片编辑器 `/zh/ai-image-editor`

- 模型下拉：默认 GPT Image 2，可切换其他模型。
- 图片上传：「点击上传第一张图片」（支持多张合成）。
- 画面比例：1:1 / 16:9 / 9:16 / 4:3 / 3:4（默认 16:9）。
- 提示词输入框：描述如何改造或合成照片。
- 按钮：「立即生成」。

## 定价 `/zh/pricing`

- 周期切换：每周 / 每季度（节省 45%）/ 积分礼包。
- 套餐：免费 $0；高级 $6.99/周（最受欢迎）；PRO $12.99/周。
- 免费：480p 无限量、5s、带水印、个人使用。
- 付费：720p/1080p 高清、无水印、商业使用权、更多并发、Upscale/延长等高级工具。

## 生成与结果处理要点

- 生成耗时：平均约 200 秒/片段；免费计划有并发限制。
- 结果：页面内预览播放，可下载 MP4；免费视频带水印。
- 私有性：默认私有；标准视频保留 24 小时，付费 AI UGC 与数字人视频永久保存。
- 下载交付：将生成视频下载到本地文件系统，再通过 `present_files` 交付；不要直接把平台预览链接当交付物。
