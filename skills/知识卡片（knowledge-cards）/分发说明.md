# 知识卡片 技能包 · 分发说明

这是一个 **WorkBuddy 技能（Skill）**，用来把任何你感兴趣的主题，做成"滑动一次出一张"的知识卡片。
本文件是给**收到这个包的学员**看的：怎么装、怎么用、怎么自己改。

---

## 一、这是什么

- 给一个主题（比如"乔布斯""私域流量""大模型术语"），它产出一组卡片。
- 每张卡片讲清一件事：**定义 / 说人话 / 为什么重要 / 常见误读 / 关联词**。
- 两种用法：
  - **对话里一张张滑着看**（边看边问）；
  - **一次性生成几十张，做成可滑动的网页卡片流**（推荐，离线能开、能转发、能录屏）。

---

## 二、安装（两步）

把整个 **`知识卡片` 文件夹**，复制到 WorkBuddy 的技能目录：

```
macOS:    ~/.workbuddy/skills/知识卡片
Windows:  C:\Users\你的用户名\.workbuddy\skills\知识卡片
```

> 提示：路径里的 `.workbuddy` 是隐藏文件夹，macOS 用 `Command + Shift + .` 显示隐藏文件；Windows 在文件管理器地址栏直接粘贴上面的路径即可。
>
> 复制完，**重启一下 WorkBuddy**（或刷新技能列表），技能就生效了。

---

## 三、怎么用

装好后，直接在 WorkBuddy 里对话触发，例如：

- "用知识卡片，给我做一套乔布斯拆解，40 张"
- "做 20 张私域流量术语卡"
- "把大模型常见概念做成可滑动的卡片"

技能会自动：确定分类 → 生成词条 → 渲染成网页 → 把 `.html` 文件交给你。
双击 HTML 用浏览器打开，**滚轮滑一下翻一张**，右上角能按板块筛选，每张卡可一键复制文案。

---

## 四、想自己改 / 自己跑脚本

包里的 `scripts/render_deck.py` 是纯 Python 标准库，无需联网、无需装包。
你只要准备一份 `terms.json`（参考 `assets/` 里的示例），然后：

```bash
python3 scripts/render_deck.py \
  --input terms.json \
  --output 我的卡片.html \
  --title "标题" \
  --kicker "英文副标题" \
  --subtitle "副标题"
```

## 五、包里有什么

```
知识卡片/
├── SKILL.md              ← 技能说明文档（核心）
├── 分发说明.md           ← 本文件
├── scripts/
│   ├── render_deck.py    ← 渲染网页卡片流（必需）
│   └── next_term.py      ← 对话模式的词库游标（可选）
├── assets/
│   ├── terms-jobs.json       ← 示例：40 张乔布斯拆解（人物五段式）
│   ├── terms-leijun.json     ← 示例：18 张雷军生平
│   ├── terms-workbuddy.json  ← 示例：17 条产品概念释义
│   ├── terms-guzi.json       ← 示例：37 条谷子经济黑话
│   └── card-template.html    ← 单卡片 HTML 模板
└── references/
    └── term-bank.md          ← 通用 starter 词库（格式参考）
```

最快上手：复制 `assets/terms-jobs.json`，把内容换成你的主题，跑上面的渲染命令。
