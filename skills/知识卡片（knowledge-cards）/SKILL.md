# 知识卡片（knowledge-cards）

## 这是什么

一个**帮你把任何感兴趣的主题"拆成一张张能读、能发、能学"的卡片**的工具。

你给它一个主题（比如"乔布斯""私域流量""大模型术语""谷子经济"），它产出一组卡片。每张卡片讲清楚一件事，包含五个模块：

- **定义**——这个东西到底是什么
- **说人话**——用一个生活化类比，让外行也能秒懂
- **为什么重要**——它凭什么值得你花时间
- **常见误读**——大多数人容易搞错的地方（信息增量最高的一栏）
- **关联词**——和它相关的其他概念，方便顺着网往下学

产出两种形态：
1. **对话卡片**：直接在聊天里一条一条滑着看，适合边看边问。
2. **网页卡片流**：一次性生成几十张，渲染成一个**可以鼠标滑动翻页的单文件 HTML**，离线能开、能转发、能录屏。这一版我们重点用它。

**关键卖点**：这个技能**不绑定任何主题**。词表由你提供，或者让 AI 现场生成；渲染引擎只认一份统一的 JSON 格式。所以不管是讲人、讲产品、讲行业黑话，还是讲考研知识点，都套同一个框架。

## 怎么用（给学员的极简上手）

### 第一步：把技能装好
把整个 `知识卡片` 文件夹，复制到 WorkBuddy 的技能目录：

```
macOS:  ~/.workbuddy/skills/知识卡片
Windows:  C:\Users\你的用户名\.workbuddy\skills\知识卡片
```

放进去后，在 WorkBuddy 里直接对话就能触发，例如：

- "用知识卡片，给我做一套乔布斯拆解，40 张"
- "做 20 张私域流量术语卡"
- "把大模型常见概念做成可滑动的卡片"

### 第二步：说出你要的主题和张数
技能会自动按主题分类、生成词条、渲染网页。你拿到的就是一个 `.html` 文件，双击用浏览器打开，滚轮滑一下翻一张。

### 第三步：拿去用
每张卡都能一键复制文案，直接拿去做：
- 短视频口播脚本
- 公众号 / 小红书图文
- 新人培训讲义
- 自己的学习笔记

## 两种模式

| 模式 | 触发方式 | "滑动"发生在哪 | 适用场景 |
|------|----------|---------------|----------|
| `swipeChat`（对话） | 你说"滑""下一个""再来一个" | 聊天对话里，一次一条 | 边看边改、要即时追问 |
| `swipeDeck`（网页） | 一次性生成 N 张 → 渲染 HTML | 浏览器里真实滚轮 / 触控板滑动 | 批量产出、离线翻阅、录屏演示 |

默认推荐 `swipeDeck`：一次生成 20–40 张，做成网页卡片流。

## 一条卡片长什么样（JSON 格式）

无论什么主题，每张卡片都长这样一份结构。你不用背，看例子就会：

```json
{
  "termId": "job-0007",
  "termZh": "1976，车库开张",
  "category": "life",
  "definition": "21 岁的乔布斯和沃兹尼亚克在养父母车库里创立苹果，首款产品 Apple I 由沃兹独自设计。",
  "plainAnalogy": "就像两个年轻人租了间车库开始捣鼓自己的东西。",
  "whyItMatters": "苹果的起点，决定了它骨子里'小团队也能改变世界'的气质。",
  "misuse": "很多人以为乔布斯是技术大牛。他不是——他负责 vision 和逼人做到极致，代码是沃兹写的。",
  "relatedTerms": ["沃兹尼亚克", "Apple I", "Apple II"],
  "metricHint": "1976 年成立，启动资金 1000 美元",
  "riskFlag": "none",
  "sourceType": "industryConsensus",
  "confidence": 0.95
}
```

字段说明（写卡片时照着填）：

| 字段 | 含义 | 注意 |
|------|------|------|
| `termId` | 编号 | 3 字母前缀 + 4 位数字，如 `job-0007`、`fin-0012`，方便管理 |
| `termZh` | 卡片标题（中文） | 2–20 字，一眼看懂 |
| `category` | 属于哪一类 | 见下方"分类" |
| `definition` | 定义 | 30–160 字，写全别截断 |
| `plainAnalogy` | 说人话 | 用生活类比，别再引入新黑话 |
| `whyItMatters` | 为什么重要 | 一句话说清价值 |
| `misuse` | 常见误读 | **最值钱的一栏**，别留空 |
| `relatedTerms` | 关联词 | 最多 5 个，串成知识网 |
| `metricHint` | 关键数字 | 没有就留空，如销量、价格、年份 |
| `riskFlag` | 风险提示 | 普通内容填 `none`；涉及合规/虚假宣传/未成年等填对应标签 |
| `confidence` | 可信度 | 0–1，越低越要标注"业内无统一口径" |

## 分类怎么定（categories）

渲染引擎**完全领域无关**：你在 JSON 顶层用 `categories` 自定义任意分类即可。例如做"金融术语"：

```json
{
  "categories": { "concept": "基础概念", "traffic": "流量玩法", "risk": "合规风险" },
  "terms": [ { "termId": "fin-0001", "category": "concept", "...": "..." } ]
}
```

如果**不写** `categories`，引擎会用一套默认 7 类知识标签，适合通用科普。

### 做「人物拆解」的黄金骨架：五段式

做人物（乔布斯、马斯克、稻盛和夫、雷军……）时，纯按年份排里程碑信息太稀。推荐这套分类，30–40 张一副：

| 分类 key | 中文标签 | 张数 | 装什么 |
|----------|----------|------|--------|
| `life` | 生平轨迹 | 6–8 | 只留决定性节点：出身 / 转折 / 终局 |
| `works` | 伟大作品 | 8–11 | 一件作品一张，写清"当时行业默认是什么、他改了什么" |
| `mind` | 核心思考 | 7–9 | 方法论与信念，每条配一句他的原话 |
| `fall` | 起落沉浮 | 5–6 | **必须写失败与暗面**，否则整副牌变成吹捧 |
| `lesson` | 创业启示 | 7–8 | 可执行的迁移结论，落到读者自己的业务上 |

> 经验：人物卡的 `misuse` 字段当**「常见误读」**用，信息增量最高。比如"乔布斯不写代码，Apple I 是沃兹设计的""图形界面是施乐发明的，苹果只是把它变成了商品"。`fall` 这段一定要写失败和争议，不然整副牌立不住。

## 渲染命令（给想自己跑脚本的同学）

网页卡片流由 `scripts/render_deck.py` 生成，纯 Python 标准库，无需联网、无需装包：

```bash
python3 scripts/render_deck.py \
  --input  terms.json \
  --output 知识卡片.html \
  --title  "乔布斯拆解 · 40张卡片" \
  --kicker "STEVE JOBS · A DECONSTRUCTION" \
  --subtitle "生平 · 作品 · 思考 · 起落 · 启发"
```

参数说明：
- `--input`：你生成的词条 JSON 文件
- `--output`：输出的 HTML 文件名
- `--title`：封面大标题
- `--kicker`：封面小字（英文副标题，可显式覆盖自动识别）
- `--subtitle`：封面副标题

打开生成的 HTML：滚轮 / 触控板滑一下翻一张，方向键 `← →` 也行；右上角可按板块筛选；每张卡有"复制本条"按钮，拿去做脚本或图文正好。

## 硬性规范（保证卡片质量）

| 规范 | 规则 |
|------|------|
| 字数 | `definition` 30–160 字；超出必须重写而非截断 |
| 去重 | 同一批卡片里，标题和别名不能重复 |
| 可信度 | `confidence < 0.6` 必须显式标注"业内无统一口径，以下为常见用法" |
| 溯源 | `sourceType=inferred`（推断）时，禁止编造出处、数据、百分比 |
| 合规 | `riskFlag` 非 `none` 时，卡片底部必须附一行风险提示 |
| 不编数 | 不编造具体市场数据；要数据请联网核验并标注来源 |
| 语言 | 正文简体中文；字段名保持英文 camelCase |

## 边界与说明

- **知识卡片不是权威出处**：法律条文、财务会计准则、需要引用官方原文的场景，应去查原文，而不是用这套生成释义。
- **能离线、能转发**：生成的 HTML 零依赖，发微信、发邮件、存本地都能直接打开。
- **只认一份 JSON Schema**：换个主题就换一份 `terms.json`，渲染、封面、话术全自适应，不用改任何代码。

---

> 这套技能的设计哲学：**知识的价值在于"被讲清楚、被串起来、被用起来"**。一张好卡片 = 一个概念讲透 + 一句人话类比 + 一个常见误区 + 一串关联线索。照这个模板，你可以用它拆任何人、任何行业、任何知识点。
