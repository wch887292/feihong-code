# web-research 技能：联网调研与竞品对标

把「一个开放问题」变成「带来源的结论 + 可继续编辑的表格」，对标 Skyalytic Wing 首页的「竞品调研」工作流。

## 工作流
1. **拆解问题**：明确调研目标、对比维度、需要哪些来源类型（官网 / 文档 / 评测 / 社区）。
2. **检索**：用 `web_search` 多组关键词（中英文各一组），筛选权威来源。
3. **抓取**：对关键页面用 `web_fetch` 提取事实，记录 URL 与日期。
4. **整理**：按维度填入对比矩阵，结论附来源；不确定项标「待实测」。
5. **交付**：输出 Markdown 报告，必要时 `write_file` 落盘为 `<主题>调研.md` 或 `.xlsx`。

## 工具约定
- `web_search`：检索关键词（目标域名受沙箱网络规则约束）。
- `web_fetch`：抓取页面正文提取事实。
- `write_file`：落盘调研报告 / 对比表。
- `xlsx` 技能（如需表格交付）：生成 Excel 对比表。

## 输出模板
```markdown
# <主题>调研报告
> 调研日期：YYYY-MM-DD | 来源：公开信息 + 实测

## 一、结论
一句话结论。

## 二、对比矩阵
| 维度 | 对象A | 对象B |
|------|-------|-------|
| ...  | ...   | ...   |

## 三、来源与置信度
- [URL]（抓取日期）— 事实点
- 待实测项：……
```

## 纪律
- 来源可溯源，结论不脱离证据；商业机密 / 未授权数据不动。
- 受沙箱网络规则约束，命中 `FH_NETWORK_DENY` 的域名自动跳过。
- 先列对比维度再填内容；长报告落盘便于继续编辑。
