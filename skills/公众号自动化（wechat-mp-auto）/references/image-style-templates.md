# 公众号配图风格模板库

这个文件记录一舟公众号常用配图风格。后续每篇文章进入配图阶段前，先从这里选择风格模板，再用 Evolink `gpt-image-2` 生成封面和正文图。

## 使用规则

1. **先选风格，再生图**：不要默认直接生成图片。进入配图阶段时，先给出 2-4 个可选风格模板，让用户选定。
2. **一篇文章只用一种主风格**：封面图和正文图必须同一套视觉系统，不能混用不同模板。
3. **模板可以微调，但要先说明**：可根据文章主题调整关键词、画面主体和中文标题，但色彩、质感、字体、构图语言要保持一致。
4. **每次验证后沉淀模板**：用户确认“这次图片不错/可以复用”时，把模板命名并写回本文件。
5. **生成结果必须落地本地**：不得依赖 Evolink 临时 URL。

## Evolink gpt-image-2 调用规范（2026-05-23 官方文档核实）

- **模型 ID**：`gpt-image-2`（不是 `gpt-image-2.0`，不要回退到 `gpt-image-1.5`）
- **Endpoint**：`POST https://api.evolink.ai/v1/images/generations`
- **size 直接用 `3:4`**（贴图原生支持，不需要 2:3 后期 overlay 拉伸）；横屏封面用 `21:9`，竖屏故事/人物特稿用 `9:16`
- **resolution**：1K (~1MP) / 2K (~4MP) / 4K (8.29MP)，贴图默认 2K，公众号长文头图可上 4K
- **风格仿写**：用 `image_urls` 传 1-16 张参考图（≤50MB/张），让新图复用旧封面的色调和构图
- **局部修改**：用 `mask_url`（白=改、黑=保留）做 inpainting，例如换标题位置的描边而不动主体
- **prompt 上限**：32,000 字符，可以写得非常详细
- **结果链接 24h 失效**，生成完立即下载本地
- **价格**：1K 单张约 $0.015，4K 高质量最高 $0.817（4K 前确认值不值）

## 模板 01：黑金数据流

**状态**：已验证  
**来源**：2026-05 公众号文章配图实战  
**适用文章**：商业、经济、科技、AI、宏观趋势、产业分析、深度洞察类公众号长文  
**不适用**：温情故事、生活方式、轻松教程、儿童/家庭温暖主题

### 视觉关键词

- 黑金
- 深色高级财经杂志感
- 数据流
- 抽象信息网络
- 电影级光影
- 高冲击力中文信息图
- 科技资本感
- 冷峻、克制、可信

### 色彩

- 主色：石墨黑、深海军蓝、暗灰
- 强调色：暖金、琥珀金
- 少量警示色：深红或暗红，只用于风险/冲突提示
- 禁止：廉价大红大紫、卡通高饱和、浅色软萌、花哨渐变

### 构图

- 封面：21:9 或 2.35:1 横屏，强中心视觉，适合公众号封面槽裁切。
- 正文图：16:9，主体清晰，留出中文标题区。
- 画面可以包含数据曲线、发光节点、金融网格、城市剪影、人物背影、机器/芯片/账本等符号。
- 不要塞满文字；中文标题少而硬，最多 1 个主标题 + 1 个短副标题。

### 字体与文字

- 字体气质：现代中文黑体、清晰、硬朗。
- 中文必须清晰可读。
- 不做手写体、毛笔字、卡通字体。
- 文字要像公众号深度文章配图，不像廉价课程海报。

### 统一提示词骨架

```text
黑金数据流风格，高冲击力中文公众号深度文章配图，深色高级财经杂志感，石墨黑和深海军蓝背景，暖金色数据流与抽象信息网络，电影级光影，克制、锋利、可信，现代中文黑体标题，中文清晰可读，少量信息图元素，画面主体明确，统一视觉系统，不要卡通，不要廉价商业海报，不要花哨渐变。
```

### 封面图提示词补充

```text
横屏公众号封面，比例 2.35:1，强中心构图，适合 900x383 裁切，标题区清晰，视觉冲击强但不杂乱。
```

### 正文图提示词补充

```text
16:9 正文配图，作为文章中段视觉停顿，主题和段落语义强相关，中文标题短而清楚，和封面保持同一套黑金数据流视觉。
```

## 模板 02：胡桃木黄昏

**状态**：草稿  
**来源**：2026-05 婆媳/家庭话题配图设计  
**适用文章**：婆媳矛盾、亲子代际、夫妻关系、家庭账本、生育决策、彩礼/相亲、中年婚姻、家务分工、原生家庭这类家庭与情感深度长文  
**不适用**：商业财经、AI 科技、人物特稿、励志鸡汤、母婴软萌、纯治愈系生活方式

### 视觉关键词

- 胡桃木黄昏
- 克制的人间烟火
- 冷峻的家庭观察
- Apartmento 杂志室内感
- Wong Kar-wai 电影暖调侧光
- 半开门、半遮窗帘、桌角一隅
- 物件叙事而非人物叙事
- 安静但有张力

### 色彩

- 主色：深胡桃木棕、暖灰、米白、奶油杏
- 强调色：低饱和墨绿、暗砖红（任选其一为本篇定调，不混用）
- 警示色：极少量铁锈红，仅用于冲突/矛盾隐喻
- 禁止：粉色系、马卡龙色、亮黄、卡通高饱和、亮金、莫兰迪过曝软糖色

### 构图

- 封面：2.35:1 横屏，弱中心构图，主体偏左或偏右，留大块负空间给标题。主体多为静物或人物局部（手、背影、桌上一双筷子、未叠的衣服、空椅子），避免正面人脸。
- 正文图：4:3 或 16:9，单一场景，景深浅，焦点集中在一个物件（碗、电饭煲、相框、账单、戒指、儿童画），背景虚化但能辨识是家庭室内。
- 光线只来自一个方向（窗户/台灯/灶台火光），制造黄昏或夜晚的暖调侧光，暗部保留。
- 不要全家福、不要笑脸、不要团圆桌、不要红双喜。

### 字体与文字

- 字体气质：现代衬线中文（思源宋体 / 方正悠宋）或克制的硬黑体，字重偏细。
- 中文标题清晰可读，字数少，最多 1 主标题 + 1 副标题。
- 不用毛笔、手写、艺术字、可爱字体。
- 标题位置贴在负空间一侧，不压主体。

### 统一提示词骨架

```text
胡桃木黄昏风格，中文家庭情感深度文章配图，克制的人间烟火与冷峻的家庭观察感，类似 Apartmento 杂志室内特辑与王家卫电影暖调侧光，深胡桃木棕、暖灰、米白与奶油杏为主，低饱和墨绿或暗砖红做点缀，单一光源黄昏侧光，景深浅，焦点在一个具体家庭物件或人物局部，避免正面人脸，画面安静但有张力，现代中文衬线或细黑体标题，中文清晰可读，留大块负空间给标题，不要粉色系，不要马卡龙色，不要卡通，不要母婴软萌，不要团圆笑脸，不要红双喜。
```

### 封面图提示词补充

```text
横屏封面，比例 2.35:1，弱中心构图，主体偏一侧，留 40% 以上负空间给中文标题，黄昏窗光或单灯侧打，适合 900x383 裁切，第一眼安静、第二眼有情绪。
```

### 正文图提示词补充

```text
4:3 或 16:9 正文配图，单一家庭场景静物特写，与段落语义强相关（账本、半碗剩饭、空婴儿床、对话框截图、抽屉里的存折等），保持胡桃木黄昏同一套色温和光线，中文标题短而克制。
```

## 模板 03：档案馆铅灰

**状态**：草稿  
**来源**：2026-05 人物/历史/哲思话题配图设计  
**适用文章**：诺奖人物、企业家史诗（稻盛和夫、王健林、宗庆后）、历史事件复盘、商业败局、智慧箴言、思想家解读、世代评传这类人物特稿与历史哲思类长文  
**不适用**：家庭情感、AI 科技教程、生活方式、轻量资讯、中老年养生号风格

### 视觉关键词

- 档案馆铅灰
- 杂志人物特稿封面
- The New Yorker / 《人物》杂志硬调摄影
- 历史档案纸质感
- 单光源伦勃朗布光
- 微粒、网点、印刷质感
- 庄重、克制、有时间厚度
- 黑白为主，单色点睛

### 色彩

- 主色：铅灰、墨黑、档案纸米白、烟褐
- 强调色：单一暗酒红 或 单一深普鲁士蓝（一篇定一色，不混用）
- 辅助：旧报纸黄、淡淡的氧化银光
- 禁止：金色（避免与黑金数据流混淆）、彩虹渐变、霓虹色、亮蓝亮红、任何卡通元素

### 构图

- 封面：2.35:1 横屏，强中心人物半身/侧脸/剪影，硬侧光从一侧切入，另一半没入阴影。背景极简或档案纹理（旧纸、网点、轻微划痕）。
- 正文图：4:5 或 3:4 竖构图（向人物特稿致敬），单人/单物，肖像感强。也可用历史场景剪影、关键物件（钢笔、勋章、签名、老照片、空会议室）。
- 不出现现代 logo、不出现具体可识别真人脸（用背影、剪影、局部、文字符号替代）。
- 画面可以叠加极轻的印刷网点、纸张纤维、档案编号字符，但不喧宾夺主。

### 字体与文字

- 字体气质：现代中文衬线（思源宋体 Heavy / 方正粗宋）做主标题，搭配细等线做副标题或日期。
- 中文清晰可读，标题字数极少（4-10 字最佳），有"刻在档案上"的分量。
- 可加一行小字日期或编号（如 "1932 — 2022" / "档案 No.07"），增强档案感。
- 不用艺术字、不用书法、不用霓虹字。

### 统一提示词骨架

```text
档案馆铅灰风格，中文人物特稿与历史哲思深度文章配图，The New Yorker 与《人物》杂志封面硬调摄影质感，铅灰、墨黑、档案纸米白与烟褐为主，单一暗酒红或深普鲁士蓝做点睛，单光源伦勃朗布光，半身/侧脸/剪影或关键档案物件，背景极简或叠加轻微旧纸、网点、印刷纤维质感，庄重、克制、有时间厚度，现代中文粗衬线主标题搭配细等线副标题，中文清晰可读，可加档案编号或年份小字，不要金色，不要彩虹渐变，不要霓虹，不要卡通，不要现代 logo，不要清晰可识别的真人脸。
```

### 封面图提示词补充

```text
横屏封面，比例 2.35:1，强中心人物剪影或侧脸局部，硬侧光，另一半没入暗部，适合 900x383 裁切，背景叠加极轻档案纸纹理，标题位于阴影一侧，黑白为主、单色点睛。
```

### 正文图提示词补充

```text
4:5 或 3:4 竖构图正文图，单人肖像或单一历史物件特写（手稿、勋章、签名、旧会议室角落），保持档案馆铅灰同一套色调和光线，可叠加档案编号小字或年份，与文章段落语义强相关。
```

## 模板 02：LIFE OS 黑绿终端

**状态**：已验证（2026-07-23 首帖 3000+ 播放，船长确认保留复用）
**来源**：《高效重复才是人生秘诀》贴图实战
**适用文章**：观点型/人生方法论/鸡汤清单/认知升级类贴图；人物证据+数据算账类内容尤佳
**不适用**：温情叙事、产品发布、需要真实照片质感的题材

### 视觉关键词

- 深黑底 #070908 + CRT 扫描线 + 胶片噪点 + 细网格
- 荧光绿 #00F58A 主强调（≤5% 画面），黄/青/粉辅助各 1-2 页
- 超大中文黑体标题（封面 118px，正文页 88-100px）
- 终端窗口 / 三联数据卡 / 时间线（LATEST 徽章）/ 对比框 / checklist
- 等宽字体英文标签（LIFE OS · RELEASE NOTES · NOTE）

### 版式资产

完整 CSS 设计系统 + 封面模板 + 每日流程 SOP 已固化在：
`YOUR_PUBLISH_WORKFLOW_PATH/templates/life-os/`（style.css / cover.html / buddha.png / README.md）

### 渲染方式

**纯 HTML/CSS + Playwright 截图**（1080×1440），中文零错字零乱码；封面主视觉（如赛博佛祖）用 Gemini `gemini-2.5-flash-image` 生成纯黑底图，CSS 羽化叠入下半屏。

- 封面大标题两行、一行 ≤8 字，关键词荧光绿

- 素材包命名必须 `01-cover.png` + `NN-名称.png`，过 `check-tietu-ready.mjs` 才算 READY
- 2026-07-23 通道现状：部分生图服务不可用时，Gemini 备用通道可用
