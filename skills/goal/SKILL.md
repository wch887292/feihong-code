# /goal 技能：目标分解与跟踪

**只读技能**：把高层目标分解为可跟踪子目标，保存到本地目标文件（不修改业务代码）。

## 工作流
1. 归一目标标题。
2. 分解子目标（并列连词分段，否则整体一个）。
3. 生成 Goal 记录：id / title / subGoals / createdAt / status=active。
4. 保存到本地目标文件，支持后续查询进度。

## 输出格式
```
【/goal】已保存目标: <title>（id: <id>）
子目标:
  - <subGoal1>
  - <subGoal2>
状态: active
```

## 纪律
- 只写目标跟踪文件，不触及其他文件。
- 子目标需可独立验证，便于跟踪进度。
