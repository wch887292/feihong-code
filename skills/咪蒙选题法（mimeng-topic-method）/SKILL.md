# 咪蒙选题法

## 核心定位

咪蒙真正厉害的不是文笔，而是选题的工业化机制：先用三个硬指标判断“值不值得写”，再用情绪、冲突、阶层正义做二次加工。本 skill 把这套机制变成可执行的筛选和改题流程，帮你把 70% 的精力花在选题上，而不是执行上。

## 触发场景

- 选题会：从一批候选题里筛出真正值得投入的那几个
- 改题：手里有一个“三好学生”式的平庸选题，想改出传播力
- 复盘：一条内容数据差，想判断是选题问题还是执行问题
- 标题打磨：内容已定，需要把标题改得更有冲突和情绪

## 工作流

### Step 1: 三个硬指标筛选（值不值得写）

一个选题必须同时过三关，缺一个就降级或放弃：

| 指标 | 判断问题 | 过关标准 |
|---|---|---|
| 覆盖面 Reach | 是 1 万人关心，还是 1 亿人关心？ | 能从小众问题切到大众焦虑（如“写好 C++”→“35 岁写代码被裁员的中年人”） |
| 争议性 Conflict | 能不能让一半人点赞、另一半人开骂？ | 议题能让人迅速站队，有讨论才有二次传播 |
| 获得感 Validation | 是否替读者说出了想说却不敢说的话？ | 读者看完想转发，借你的内容给自己贴标签 |

### Step 2: 情绪 × 覆盖矩阵定级

| 情绪强度 | 覆盖范围 | 策略 | 例子 |
|---|---|---|---|
| 高情绪 | 广覆盖 | 必写 | 婚姻背叛、阶层跨越、职场不公 |
| 低情绪 | 广覆盖 | 不写 | 天气变化、常规新闻 |
| 高情绪 | 窄覆盖 | 选写 | 小众圈层恩怨，但能折射普遍人性 |
| 低情绪 | 窄覆盖 | 绝不写 | 纯干货、冷门知识 |

选题公式：**影响力选题 = 底层情绪（动力）× 认知冲突（阻力转化）÷ 共鸣门槛（成本）**

- 动力：是否触及愤怒、焦虑、优越感这三个开关？
- 转化：是否打破常规认知、制造了讨论空间？
- 降本：标题是否足够口语化、能被直接复述？

### Step 3: 二次加工（怎么写）

对通过筛选的选题，按三种手法降维打击：

1. **情绪优先于信息**：干货必须包一层情绪糖衣，让读者先被击中再学到东西。
2. **二元对立制造冲突**：人为树立“假想敌”，明确指出反对什么、支持什么。普通表达“职场新人要努力工作”→ 咪蒙式“我月薪五万，凭什么要给月薪五千的老板擦桌子？”
3. **私人琐事上升为阶层正义**：把个案拔高到群体高度。一个员工被开除 → 寒门与资本；一次消费选择 → 女性独立与商家操控。

### Step 4: 标题改写模板

| 模板 | 普通题 | 咪蒙式 |
|---|---|---|
| 干货 → 阶层焦虑 | 如何提升职场竞争力？ | 那个 35 岁还在埋头努力的人，终于被公司一脚踢开了 |
| 建议 → 攻击性判断 | 女性如何理性消费？ | 那些劝你“对自己好点”的商家，正在合伙毁掉你的下半辈子 |
| 产品功能 → 价值观筛选 | 酒店早餐很好吃 | 别让你的人生，活成酒店“免费早餐”的样子 |
| 趋势 → 优越感表达 | 年轻人为什么不爱聚会？ | 30 岁以后，请离那些“看起来很忙”的人远一点 |

### Step 5: 工业化测试

学机制而不是学语气：每天产出足量候选题（参考咪蒙团队 50 选 1），投票筛选后继续改十几个版本，小范围测试看数据再决定发不发。

## 输出格式

```text
候选选题清单：...
三指标评分表（覆盖面 / 争议性 / 获得感）：...
矩阵定级（必写 / 不写 / 选写 / 绝不写）：...
推荐选题 + 二次加工后的 3-5 个标题版本：...
放弃选题及原因：...
测试建议：...
```

## Gotchas

1. **不要只学语气**
   解释：攻击性措辞是结果不是方法。先过三指标和矩阵，再谈表达；顺序反了就是单纯喷人。
2. **纯干货不要硬发**
   解释：低情绪 + 窄覆盖的题直接放弃或包情绪糖衣，不要指望“内容好自然有人看”。
3. **产品说明书不是 IP**
   解释：复读产品功能的内容没有传播势能，必须把选题升级为价值观筛选（你失去什么、谁在收割你、你和普通人的分界在哪）。
4. **冲突要有事实底座**
   解释：制造对立不等于编造假案例；用真实素材做极端化表达，不虚构人物和数据。
5. **留一道价值观闸门**
   解释：涉及性别、阶层、地域等敏感对立时，评估账号定位和平台风险再决定锐度，不为流量越过底线。
