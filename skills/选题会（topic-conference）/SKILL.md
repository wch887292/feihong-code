# 选题会

## 核心定位

选题会是正文之前的共同思考环节。它把一个模糊想法整理成可确认、可查证、可执行的写作简报。

它主要解决四个问题：

- 这篇内容真正要解决谁的问题？
- 读者看完应该获得什么判断或行动？
- 哪个角度最值得写，为什么是现在？
- 哪些事实、案例和表达边界必须先确认？

## 触发场景

- 重要原创、深度文章或系列内容开始前
- 手里有多个方向，不知道选哪个
- 有参考材料，但缺少自己的判断和主线
- 需要把研究、讨论和写作要求整理成一份简报

轻量润色、已有明确大纲的续写和单纯改标题，可以直接执行，不必完整召开选题会。

## 工作流

### 1. 明确任务

先确认主题、目标读者、内容形式、使用场景、期望结果和不能触碰的边界。信息不足但不影响启动时，写明假设后继续。

### 2. 整理材料

把输入分成四类：已知事实、他人观点、待验证判断、可使用素材。事实和观点分开记录，不把推测写成结论。

### 3. 比较角度

围绕同一个主题提出少量真正不同的切入角度，并比较：读者关系、现实利益、独特判断、事实支撑和表达风险。

### 4. 聚焦主线

选择一个中心问题，明确核心判断、主要冲突、内容承诺和读者看完后的下一步。需要用户做选择时，一次只推进一个关键问题。

### 5. 形成写作简报

输出标题方向、中心命题、结构顺序、事实清单、反方观点、案例需求、风险边界和待确认事项。简报确认前，不把准备工作当成成稿。

### 6. 等待开写信号

用户确认方向后再进入正文写作。写作过程中发现新的事实问题，应标记为待核，不擅自改变已经确认的主线。

## 脱敏过程案例

以下案例只展示执行过程，不包含真实项目、账号、客户或未公开材料。

### 案例 1：把“中年转型”收敛成一篇可写内容

输入：用户想写一篇关于中年职场转型的内容，但只有一个泛方向。

过程：

1. **明确任务**：确认目标读者是有稳定工作但担心未来变化的人，内容目标是帮助读者判断“现在要不要转、怎么降低试错成本”。
2. **整理材料**：把公开行业变化、个人经历片段和常见误区分成事实、观点、待验证判断和素材。
3. **比较角度**：比较“转型方法清单”“成功故事”“错误转型代价”三个方向，判断第三个更容易形成现实利益和冲突。
4. **聚焦主线**：确定核心问题为“转型前先保住什么底线”，中心判断为“转型不是换赛道，而是先重排风险顺序”。
5. **形成简报**：输出标题方向、结构顺序、需要核实的行业事实、需要补充的失败案例、最强反方和表达边界。

结果：选题会从“想写中年转型”推进到一份可确认的写作简报，下一步是等待用户确认主线，而不是直接写全文。

### 案例 2：把“AI 工具提效”从工具清单改成判断型内容

输入：用户提供一批 AI 工具材料，想做一篇提效内容。

过程：

1. **明确任务**：确认内容不是产品推荐，而是帮助读者判断哪些工作值得交给工具、哪些工作必须保留人的判断。
2. **整理材料**：把工具功能、公开演示、用户实际工作流程和一个失败使用场景分开记录。
3. **比较角度**：比较“工具合集”“效率教程”“工作流重构”三种写法，判断“工作流重构”更有独立观点。
4. **聚焦主线**：确定中心问题为“为什么工具越多，有些人反而更忙”，内容承诺为“帮读者重新分配人、工具和检查环节”。
5. **形成简报**：输出中心判断、三层结构、待核功能点、一个失败案例需求、反方观点和避免夸大效果的表达边界。

结果：选题会把一批工具材料整理成有主线的内容准备，不复制工具介绍，也不把功能宣传当成事实。

## 输出格式

~~~text
选题：...
目标读者：...
内容形式：...
核心问题：...
推荐角度：...
中心判断：...
内容承诺：...
结构顺序：...
需要核实的事实：...
需要补充的案例：...
最强反方：...
表达边界：...
下一步：等待确认 / 补充材料 / 开始写作
~~~

## Gotchas

1. **不要把资料整理当成选题会完成**
   解释：选题会必须形成明确主线和写作简报，不能只堆链接和摘要。

2. **不要边讨论边偷偷写完整正文**
   解释：先确定方向，再写正文，能减少结构反复和事实漂移。

3. **不要把未经核实的内容写成事实**
   解释：数字、时间、人物、案例和因果关系都要标记来源状态。

4. **不要复制参考内容的表达**
   解释：参考材料用于理解问题和结构，最终内容必须重新组织并形成自己的判断。

5. **不要为了显得深刻而扩大范围**
   解释：每个问题都要能改变当前内容的主线、事实取舍、案例安排或读者获得感。

6. **不要承诺流量结果**
   解释：选题会提高准备质量，不保证平台分发、阅读量或转化结果。

## 何时补充材料

- 需要时事、行业数据或具体案例时，补充公开来源或用户提供的材料。
- 需要确认品牌口径、法律边界或敏感表达时，先标记待确认，不自行猜测。
- 只有在用户确认主线后，才进入完整写作或后续制作流程。
