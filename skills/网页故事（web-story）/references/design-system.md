# 视觉框架清单

一页框架，够用就好。每页做视觉决策前对照一遍。

## 布局

- 移动优先：先写 375px 布局，桌面端用 `min-width` 媒体查询做加法。
- 容器最大宽度 1080~1200px；章节间距大、卡片内间距小，层级靠间距拉开。
- 间距用 8 的倍数（8/16/24/40/64）。

## 配色与字体

- 主色 1 个 + 中性色 3~4 阶 + 强调色 1 个，每页只允许一个视觉记忆点。
- 正文与背景对比度 ≥ 4.5:1。
- 中文用系统字体栈（`-apple-system, "PingFang SC", "Noto Sans SC", sans-serif`），字号层级不超过 5 级。
- 圆角、阴影全站各统一一档。

## 动效

- CSS transition 能解决就不用动画库。
- 标配三样：滚动进入淡入、hover 微浮起、锚点平滑滚动。
- 时长 150~300ms；尊重 `prefers-reduced-motion`。

## 反 AI 味（最重要的几条）

- 标题写论点，不写类目名（"行业分析"→"这个行业正在发生的一件事"）。
- 数字必须带来源；没来源就写事实，不写数字。
- 不用 emoji 当图标，不用紫蓝渐变 hero 配三栏卖点卡片。
- 不写"赋能""一站式""全方位"这类空话。

## 交互

- 锚点导航、卡片展开、维度切换 Tab 三样覆盖绝大多数需求。
- 可点元素触控高度 ≥ 42px。
- 关键信息不要藏在 hover 里（手机没有 hover）。
