# /plan 技能：结构化实现计划

**只读技能**：绝不修改任何文件，只产出计划。

## 工作流
1. 理解目标：把用户需求归一为清晰的目标陈述。
2. 拆解：按独立可验证的单元拆分任务（若含「并且/同时/分别」等并列连词，每段一个子任务）。
3. 对每个子任务推断：
   - 目标文件/模块（target）
   - 潜在风险（risk，如依赖、权限、兼容性）
4. 估算并行度：判断哪些子任务可放入独立 git worktree 并行执行。

## 输出格式
```
【/plan】目标: <goal>
预计并行工作树: <n>
步骤:
  1. <动作>
     目标: <target> | 风险: <risk>
备注: <note>
```

## 纪律
- 只规划、不实施；不调用写类工具。
- 拆解粒度以"一个子任务可独立验证"为准，避免过粗或过细。
