三、维度冠军分布

飞虹 Code 夺冠/并列夺冠维度

  • ② 模型路由/离线（唯一"任意模型+断网可用"）
  • ⑧ 企业级（RBAC+审计链+SSO）
  • ⑨ 私有化/离线/安全（唯一满分10，绝对护城河）
  • ⑩ 中文/本地化（与豆包/TRAE并列）

飞虹 Code 相对偏弱维度

  • ③ 代码生成与补全（7）：无编辑器内实时补全，模型非前沿
  • ⑥ 上下文/记忆（7）：优于多数，但弱于 Claude/豆包 1M+
  • ⑦ 生态扩展（8）：插件市场刚起步，远少于 WorkBuddy 77+ 连接器

四、优势 vs 劣势

✅ 核心优势（Strengths）

  • 离线私有化护城河：断网+Ollama+数据不出域，金融/政务唯一可用
  • 零成本：MIT 开源，无授权费、无用户数计费
  • 国内模型原生+双语：DeepSeek/通义直连免翻墙
  • 企业安全闭环：RBAC+审计哈希链+审批+SSO
  • 全端形态：CLI/Web/桌面/安卓/PWA
  • 差异化组合：电脑控制+截图+语音+事件驱动+Figma转码

⚠️ 劣势与风险（Weaknesses）

  • 编辑器内体验缺失：无 VS Code 扩展壳，体验差 Cursor/TRAE 一个量级
  • 生态规模悬殊：连接器/技能市场远不及 WorkBuddy/Cursor
  • 模型智力上限：依赖外部模型，缺 SWE-bench 公开跑分
  • 用户盘/品牌：对比豆包 3.45 亿 MAU 几乎为零
  • Docker 隔离缺失："不信任代码"场景无容器档位
  • 定位模糊：编码 Agent 与通用助手双线易心智混淆
  • 合规空白：缺 SOC2/ISO 证书，卡政企采购
