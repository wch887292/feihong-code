# summarize 技能：结构化摘要

把冗长内容压缩为「一眼能抓住重点」的结构化摘要，保留来源与关键结论。

## 工作流
1. **识别来源**：文本直接处理；文件用 `read_file`；网页 / URL 用 `web_fetch`。
2. **判定长度**：超长内容先分段或抓取关键段落，避免截断丢失重点。
3. **提取结构**：按「核心结论 → 关键要点（3-7 条）→ 行动项 / 风险 → 来源」组织。
4. **输出**：默认中文 Markdown；用户要表格时给对比表。

## 工具约定
- `read_file`：读取本地文件内容。
- `web_fetch`：抓取网页正文。
- `write_file`（可选）：长摘要落盘为 `.md`。

## 输出模板
```markdown
## 摘要：<标题>
**核心结论**：一句话说清结果。

**关键要点**
- 要点1（含依据）
- 要点2
- 要点3

**行动项 / 风险**
- [ ] 需跟进：……
- ⚠️ 风险：……

**来源**：<文件 / URL>
```

## 纪律
- 不编造来源中没有的信息；不确定处标注「待确认」。
- 保留可溯源引用（章节 / 段落 / URL）。
- 摘要长度不超过原文 20%，重点优先。
