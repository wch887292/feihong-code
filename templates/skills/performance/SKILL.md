# 性能优化分析

<!-- 模板占位：使用 `fhcode skill-new <name> --template performance` 复制并定制 -->

## 触发
当用户说"太慢了/性能问题/优化下速度/内存泄漏"时使用。

## 执行步骤
1. 先量化：不要凭空优化，指出如何测量（benchmark、profile、日志耗时）
2. 常见瓶颈排查：
   - 算法复杂度（O(n²)→O(n log n)）
   - 重复计算/循环内 I/O
   - 无缓存/缓存失效策略
   - 阻塞（同步 I/O、串行请求可并行化）
   - 内存：大对象、未释放引用、流式处理
3. 给出：瓶颈定位 → 量化方法 → 优化方案 → 预期收益 → 验证方法

## 输出格式
瓶颈分析表 + 优化前后对比 + 收益预估。
