三年历程

2023 年 · 起点

三个开发者的初心

在泉州一家制造业AI服务公司的办公室里，三个开发者围着一台老旧的台式机，讨论着一个大胆的想法：做一个真正能自主写代码的AI助手。

"为什么AI只能回答问题，而不能动手写代码？"

M0 脚手架工程初始化
2024 年 · 探索

从 Mock 到真实模型

第一年，我们走了很多弯路。最初只能用 Mock 驱动，代码生成完全不可能。接入 DeepSeek、通义千问后，终于看到了希望。

"每一次 API 超时都是一次教训，每一次报错都是成长的机会。"

M1 模型路由M2 多代理
2025 年 · 突破

企业级能力与自我进化

第二年，客户需求倒逼我们做出企业级功能：RBAC权限、审计链、多租户隔离。同时，我们实现了自我进化——让AI从失败中学习。

"一个不会自我修复的AI，只是一个高级脚本。"

M3 会话恢复M4 企业级M6 自我进化
2026 年 · 发布

v0.5.1 正式发布

经过上千次测试迭代，飞虹 Code 终于完成 M0→M9.1 全部里程碑。从离线演示到企业部署，从个人开发到团队协用。

"这不仅是代码，是三年心血的结晶。"

走过的坑

🔥

并发控制难题

多代理并行时，API 限流导致大量 429 错误。解决方案：引入队列机制 + 指数退避重试。

🔒

企业安全合规

客户要求审计链不可篡改。解决方案：实现 SHA-256 哈希链，每次写入强制追加。

🧠

上下文管理

长对话超出 Token 限制。解决方案：实现智能压缩算法，保留关键信息+摘要早期内容。
