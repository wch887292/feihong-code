# 评分标准与对比模板

## 一、各题评分细则（0-10 分）

### Q1 Python LRU 缓存（权重 15%）

| 分数 | 标准 |
|------|------|
| 9-10 | 代码可直接运行，get/put 均为 O(1)，含 3 行使用示例，无语法错误 |
| 7-8 | 功能正确，O(1) 达标，但示例不足 3 行或缺少边界处理 |
| 5-6 | 能实现基本 LRU，但时间复杂度非 O(1)（如用 list 轮转） |
| 3-4 | 代码有语法错误或逻辑不完整 |
| 0-2 | 完全无法运行或答非所问 |

**机器判据**：`python3 -c "import ast; ast.parse(code)"` 通过得 3 分；含 `class` + `def get` + `def put` 得 4 分；含 `OrderedDict` 或 `dict`+`Node` 结构得 3 分。

---

### Q2 TypeScript 防抖（权重 15%）

| 分数 | 标准 |
|------|------|
| 9-10 | 类型注解完整（含返回值类型 `(...args)=>void`），支持 leading/maxWait/cancel，无 any |
| 7-8 | 功能基本正确，类型注解有少量缺失或用了 any |
| 5-6 | 实现了基本防抖，缺少 leading 或 maxWait 或 cancel |
| 3-4 | 代码有语法错误 |
| 0-2 | 完全无法运行 |

**机器判据**：`npx tsc --noEmit` 通过得 4 分；含 `function debounce` 得 3 分；含 `leading`/`maxWait`/`cancel` 关键词各得 1 分。

---

### Q3 中文解释超额累进分红（权重 10%）

| 分数 | 标准 |
|------|------|
| 9-10 | 概念解释准确（分段累进+按档计税），计算例子数字正确，字数 ≤100 字 |
| 7-8 | 解释基本正确，例子有小误差或字数略超 |
| 5-6 | 解释含混，例子缺失 |
| 3-4 | 答非所问 |
| 0-2 | 空白 |

**机器判据**：字数 ≤100 得 2 分；含"累进"/"分段"/"档"关键词得 2 分；含具体数字计算得 3 分；含"税"/"扣除"/"基数"得 3 分。

---

### Q4 严格 JSON 输出（权重 10%，机器判）

| 分数 | 标准 |
|------|------|
| 10 | 输出严格 JSON，`JSON.parse` 成功，`status==="ok"`，items 为 3 个 1-20 的质数 |
| 7 | JSON 可解析但字段不完全符合要求 |
| 5 | 输出包含 JSON 但被代码块包裹 |
| 0 | 完全无法解析 |

**机器判据**：`node -e "JSON.parse(require('fs').readFileSync('q4.txt','utf8'))"` 成功得 5 分；`status==="ok"` 得 2 分；items 为数组且长度=3 得 1 分；3 个元素均为质数且 ≤20 得 2 分。

---

### Q5 5 句产品文案（权重 10%，机器判）

| 分数 | 标准 |
|------|------|
| 10 | 恰好 5 句（以句号/问号/感叹号分隔），主题切题，句子间有空行 |
| 7 | 4 或 6 句，主题基本切题 |
| 5 | 3 句或 7 句 |
| 0 | 句数偏差 ≥3 或完全跑题 |

**机器判据**：以 `[。！？.!?]` 分割后计数，恰好 5 句得 5 分；每句间有空行（`\n\n`）得 2 分；含"私有化"/"本地"/"部署"关键词得 3 分。

---

### Q6 甲乙丙推理题（权重 20%）

| 分数 | 标准 |
|------|------|
| 9-10 | 推理链完整（假设→验证→排除→结论），结论正确（乙做了好事），逻辑无矛盾 |
| 7-8 | 结论正确，推理步骤有跳跃 |
| 5-6 | 结论正确但推理不完整 |
| 3-4 | 结论错误但推理过程有可取之处 |
| 0-2 | 空白或完全错误 |

**机器判据**：含"假设"/"验证"/"排除"/"结论"等推理链路词得 3 分；最终答案为"乙"得 4 分；提及"甲说真话则乙丙矛盾"等关键推理得 3 分；字数 ≥100 得 2 分；逻辑自洽（无自相矛盾）得 3 分。
